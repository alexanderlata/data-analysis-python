# Наборы данных

Все файлы в формате CSV: разделитель ячеек `,`, десятичный разделитель `.`, кодировка UTF-8. Описание переменных каждого набора в [data-description.md](data-description.md).

| Файл | Наблюдений | О чём | Источник |
|---|---:|---|---|
| `countries.csv` | 62 | показатели стран: ИРЧП, ВВП на душу населения, население, безработица, продолжительность жизни | учебный набор |
| `default.csv` | 6 778 | дефолт по студенческим займам и характеристики заёмщиков | учебный набор |
| `Diamond.csv` | 308 | цены бриллиантов и их характеристики | Chu (2001), Journal of Statistics Education |
| `diamonds.csv` | 53 940 | цены и характеристики 54 тысяч бриллиантов | пакет ggplot2 для R |
| `Electricity.csv` | 158 | издержки и выпуск электростанций США | Christensen, Greene (1976) |
| `Labour.csv` | 569 | капитал, труд и выпуск бельгийских фирм | Verbeek (2004) |
| `sleep75.csv` | 706 | сон, работа и характеристики работников США | Biddle, Hamermesh (1990), сборник Wooldridge |
| `wage1.csv` | 526 | почасовая зарплата и характеристики работников | сборник Wooldridge |
| `wage2.csv` | 935 | месячная зарплата, IQ, образование | Blackburn, Neumark (1992) |

Данные сквозного юридического кейса лежат в папке [legal](legal/): ДТП с пострадавшими в Брянской и Московской областях по данным ГИБДД с портала «Карта ДТП», по две таблицы на регион; описание переменных в [legal/README.md](legal/README.md).
