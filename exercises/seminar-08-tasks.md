## Часть Б. Основные задачи

### Б1. Линия по периоду

Линия по времени — первый график любого отчёта. Одна функция вместо копирования пяти строк для года, месяца и часа. Ловушка: `value_counts` считает верно, но сортирует по убыванию, а линии нужен порядок периодов — `sort_index`.

Реализуйте функцию `count_line(periods, title, xlabel, ax=None)`, которая рисует линию числа ДТП по периодам. Аргументы: `periods` — series с периодом каждого ДТП: год, месяц, час или день недели, целые числа; `title` — заголовок, строка; `xlabel` — подпись оси X, строка; `ax` — оси для рисования; если не переданы, функция создаёт свои: fig, ax = plt.subplots(figsize=(8, 4)). Возвращаемое значение: объект Axes с одной линией с маркерами: по оси X значения периода по возрастанию, по оси Y число ДТП в каждом; заголовок title, подпись оси X xlabel, подпись оси Y «Число ДТП». Входной Series не меняется.

Подсказка: разделы 1–2 ноутбука занятия: `value_counts().sort_index()`, метод `.plot(ax=ax, marker='o')` у Series, `ax.set_title`, `ax.set_xlabel`, `ax.set_ylabel`; проверка `if ax is None:` в начале функции.

Проверка в ноутбуке: ДТП области по годам через count_line; печатаются число точек линии и число ДТП в последней, оба вводятся в тест.

### Б2. Самые частые значения столбцами

Столбчатая диаграмма нужна для любого категориального столбца отчёта: районы, виды ДТП, погода, нарушения. У всех одна беда — длинные названия и порядок столбцов; функция решает обе раз и навсегда.

Реализуйте функцию `top_bars(values, n, title, ax=None)`, которая рисует горизонтальные столбцы для самых частых значений. Аргументы: `values` — series с категориями, например район или вид ДТП; `n` — сколько самых частых значений показать, целое число; `title` — заголовок, строка; `ax` — оси для рисования; если не переданы, функция создаёт свои: fig, ax = plt.subplots(figsize=(8, 4)). Возвращаемое значение: объект Axes с n горизонтальными столбцами: самое частое значение сверху, длина столбца — число ДТП с этим значением; заголовок title, подпись оси X «Число ДТП». Входной Series не меняется.

Подсказка: раздел 3 ноутбука занятия: `value_counts().head(n)`, метод `.plot.barh(ax=ax)`; самое частое сверху даёт либо срез `[::-1]` перед рисованием, либо `ax.invert_yaxis()` после — тесты принимают оба пути.

Проверка в ноутбуке: восемь районов области с наибольшим числом ДТП через top_bars; печатаются верхний и восьмой столбцы, в тест вводятся восьмой район и его число.

### Б3. Доли с накоплением

Столбцы с накоплением отвечают на вопрос «из чего состоит»: тяжесть ДТП при разной погоде, виды ДТП по годам, исход по ролям участников. Доли считаются внутри группы, `normalize='index'`; порядок слоёв задаёт список, а не алфавит.

Реализуйте функцию `share_bars(rows, columns, order, title, ax=None)`, которая рисует столбцы с накоплением долей. Аргументы: `rows` — series с группами, например погода или год; по строкам будущей сводки; `columns` — series той же длины с тем, что раскладывается на доли, например тяжесть; по столбцам сводки; `order` — список значений columns в порядке слоёв снизу вверх; остальные значения не показываются; `title` — заголовок, строка; `ax` — оси для рисования; если не переданы, функция создаёт свои: fig, ax = plt.subplots(figsize=(8, 4)). Возвращаемое значение: объект Axes, где на каждую группу один столбец, слои — доли значений внутри группы, сумма слоёв 1; заголовок title, подпись оси Y «Доля ДТП», легенда со значениями из order, подписи групп без поворота. Входные Series не меняются.

Подсказка: раздел 3 ноутбука занятия: `pd.crosstab(rows, columns, normalize='index')[order]`, метод `.plot(kind='bar', stacked=True, rot=0, ax=ax)`; легенду pandas ставит сам.

Проверка в ноутбуке: тяжесть ДТП области по четырём главным погодам через share_bars; печатается таблица долей, снятая с объекта; в тест вводятся доля ДТП с погибшими в дождь и доля лёгких в снегопад.

### Б4. Гистограмма целых значений

Гистограмма показывает распределение, а не список категорий: расстояние между столбцами хранит шкалу. Если ни в одном ДТП не было 14 раненых, на месте 14 остаётся пробел, а столбчатая диаграмма из `value_counts` этот пробел съела бы. `discrete=True` ставит столбец точно на целое значение.

Реализуйте функцию `count_hist(values, title, xlabel, ax=None)`, которая рисует гистограмму целых значений. Аргументы: `values` — series целых чисел, например час ДТП, число раненых или участников; `title` — заголовок, строка; `xlabel` — подпись оси X, строка; `ax` — оси для рисования; если не переданы, функция создаёт свои: fig, ax = plt.subplots(figsize=(8, 4)). Возвращаемое значение: объект Axes со столбцом на каждое целое значение от наименьшего до наибольшего: высота — число ДТП с этим значением, значения, которых нет, дают пустое место; заголовок title, подпись оси X xlabel, подпись оси Y «Число ДТП». Входной Series не меняется.

Подсказка: раздел 4 ноутбука занятия: `sns.histplot(x=values, discrete=True, ax=ax)`; seaborn сам подписывает ось Y словом `Count`, подпись заменяется через `ax.set_ylabel`.

Проверка в ноутбуке: раненых в одном ДТП области через count_hist; печатаются самый высокий столбец и число ДТП с четырьмя ранеными, оба вводятся в тест.

### Б5. Ящики по группам

Ящик с усами сравнивает распределения по группам без сводок: медиана, квартили и выбросы видны сразу. `order` убирает случайные и малые группы и задаёт порядок сравнения.

Реализуйте функцию `box_by(df, value, by, order, title, ax=None)`, которая рисует ящики с усами по группам. Аргументы: `df` — таблица; `value` — имя числового столбца, строка; `by` — имя столбца с группами, строка; `order` — список групп в порядке слева направо; остальные группы не показываются; `title` — заголовок, строка; `ax` — оси для рисования; если не переданы, функция создаёт свои: fig, ax = plt.subplots(figsize=(8, 4)). Возвращаемое значение: объект Axes с ящиком на каждую группу из order; подписи осей — имена столбцов by и value, заголовок title. Таблица не меняется.

Подсказка: раздел 4 ноутбука занятия: `sns.boxplot(data=df, x=by, y=value, order=order, ax=ax)`; seaborn сам подписывает оси именами столбцов.

Проверка в ноутбуке: стаж водителей области без кодов по виду ДТП через box_by; числа для теста печатаются сводкой, вводятся медианы для наезда на препятствие и съезда с дороги.

### Б6. Тепловая карта двух признаков

Тепловая карта — сводная таблица, в которой читают цвет, а не 168 чисел. Функция превращает любую пару признаков в карту; имена осей берутся из имён Series, иначе на обеих осях окажется `datetime`.

Реализуйте функцию `heat_table(rows, columns, title, ax=None)`, которая рисует тепловую карту числа ДТП по двум признакам. Аргументы: `rows` — series с признаком по строкам карты, с именем, заданным через rename, например месяц; `columns` — series той же длины с признаком по столбцам карты, с именем, например день недели; `title` — заголовок, строка; `ax` — оси для рисования; если не переданы, функция создаёт свои: fig, ax = plt.subplots(figsize=(8, 4)). Возвращаемое значение: объект Axes, где клетка — число ДТП с таким сочетанием значений, цвет один, чем темнее, тем больше; подписи осей — имена Series, заголовок title. Входные Series не меняются.

Подсказка: раздел 5 ноутбука занятия: `pd.crosstab(rows, columns)`, `sns.heatmap(table, cmap='Blues', ax=ax)`; seaborn подписывает оси именами таблицы, а `rename` у Series задаёт имя: `df['datetime'].dt.month.rename('Месяц')`.

Проверка в ноутбуке: месяц × день недели по таблице области через heat_table; печатается наибольшее значение и его клетка, в тест вводится значение.

### Б7. Точки на координатах

Диаграмма рассеяния координат — самая быстрая проверка географии данных: нули и переставленные пары уходят за рамку области, а внутри рамки точки складываются в дороги и города. Рамка берётся с небольшим запасом по границам области. Настоящая карта с подложкой — на семинаре 9.

Реализуйте функцию `points(df, box, title, ax=None)`, которая рисует места ДТП внутри рамки. Аргументы: `df` — таблица ДТП со столбцами lat и lon; `box` — кортеж из четырёх чисел (lat_min, lat_max, lon_min, lon_max): рамка области, границы включаются; `title` — заголовок, строка; `ax` — оси для рисования; если не переданы, функция создаёт свои: fig, ax = plt.subplots(figsize=(8, 6)). Возвращаемое значение: объект Axes, на котором нарисованы только ДТП внутри рамки: по оси X долгота, по оси Y широта, точки маленькие и полупрозрачные, s=2 и alpha=0.3; подписи осей «Долгота» и «Широта», заголовок title. Таблица не меняется.

Подсказка: раздел 6 ноутбука занятия: `lat_min, lat_max, lon_min, lon_max = box` распаковывает кортеж; две маски через `between` и `&`; `ax.scatter(inside['lon'], inside['lat'], s=2, alpha=0.3)`.

### В2. Столбцы рядом с подписями значений

Столбцы рядом сравнивают числа между группами, столбцы с накоплением показывают состав внутри группы. Подписи значений над столбцами избавляют читателя от линейки: число видно без шкалы.

Реализуйте функцию `grouped_bars(rows, columns, order, title, ax=None)`, которая рисует столбцы рядом с подписями значений. Аргументы: `rows` — series с группами, например годы; по строкам будущей сводки; `columns` — series той же длины с тем, что сравнивается, например вид ДТП; по столбцам сводки; `order` — список значений columns в порядке столбцов внутри группы; остальные значения не показываются; `title` — заголовок, строка; `ax` — оси для рисования; если не переданы, функция создаёт свои: fig, ax = plt.subplots(figsize=(8, 4)). Возвращаемое значение: объект Axes, где на каждую группу столбцы стоят рядом, высота — число ДТП, над каждым столбцом подпись с числом; легенда со значениями из order, подпись оси Y «Число ДТП», заголовок title, подписи групп без поворота. Подсказка: раздел 3 ноутбука занятия: `pd.crosstab(rows, columns)[order].plot(kind='bar', rot=0, ax=ax)` рисует столбцы рядом; подписи ставит `ax.bar_label(container)` для каждого набора столбцов из `ax.containers`.
