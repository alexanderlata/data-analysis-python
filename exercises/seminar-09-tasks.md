### Б1. Гистограмма с накоплением по группам

Гистограмма семинара 8 отвечала на вопрос «сколько», гистограмма с накоплением отвечает «сколько и из чего»: вечерний пик ДТП состоит из тёмного времени. `hue` и `multiple='stack'` делают это одной строкой; без `discrete=True` столбцы не совпадают с целыми значениями, без `multiple='stack'` слои накладываются друг на друга, и высоты лгут.

### Б2. Плотности по группам

Плотность сравнивает форму распределений у групп разного размера: женщин-водителей в таблице области 3 553, мужчин 21 323, и на общей гистограмме столбцы женщин утонули бы внизу. При `common_norm` по умолчанию seaborn делит одну единицу площади между группами по их размеру, и кривая малой группы выходит плоской; `common_norm=False` нормирует каждую группу отдельно, и сравниваются формы, а не размеры.

Реализуйте функцию `density_by(df, column, group, title, xlabel, ax=None)`, которая рисует кривые плотности по группам. Аргументы: `df` — таблица; `column` — имя числового столбца, строка: стаж, год выпуска; `group` — имя столбца с группами, строка: пол, здоровье; `title` — заголовок, строка; `xlabel` — подпись оси X, строка; `ax` — оси для рисования; если не переданы, функция создаёт свои: fig, ax = plt.subplots(figsize=(8, 4)). Возвращаемое значение: объект Axes с одной кривой плотности на группу, линии без заливки, каждая нормирована отдельно: площадь под каждой кривой равна 1; заголовок title, подпись оси X xlabel, подпись оси Y «Плотность», легенда с названиями групп. Таблица не меняется.

Подсказка: раздел 1 ноутбука занятия: `sns.kdeplot(data=df, x=column, hue=group, common_norm=False, ax=ax)`; seaborn подписывает ось Y словом `Density`, подпись заменяется через `ax.set_ylabel`.

Проверка в ноутбуке: стаж водителей области без кодов по полу через density_by; печатаются округлённые значения стажа, при которых кривые выше всего, по возрастанию, оба вводятся в тест.

### Б3. Корреляционная карта по списку столбцов

Корреляционная матрица — одна команда и один график для всех числовых столбцов отчёта. `corr()` по всей таблице падает на тексте, список столбцов нужен и ему, и читателю: координаты и номера в матрице ничего не значат. Последовательная палитра прячет знак корреляции, расходящаяся с нулём в середине показывает его цветом.

Реализуйте функцию `corr_heat(df, columns, title, ax=None)`, которая рисует тепловую карту корреляций числовых столбцов. Аргументы: `df` — таблица; `columns` — список имён числовых столбцов; `title` — заголовок, строка; `ax` — оси для рисования; если не переданы, функция создаёт свои: fig, ax = plt.subplots(figsize=(6, 5)). Возвращаемое значение: объект Axes с тепловой картой матрицы df[columns].corr(): расходящаяся палитра с нейтральным цветом в нуле, красное — положительная связь, синее — отрицательная; в каждой клетке значение с двумя знаками после запятой; подписи делений осей — имена столбцов; заголовок title. Подсказка: раздел 2 ноутбука занятия: `sns.heatmap(df[columns].corr(), cmap='coolwarm', center=0, annot=True, fmt='.2f', ax=ax)`.

Проверка в ноутбуке: стаж, год выпуска машины и число нарушений у водителей области через corr_heat; печатаются число подписанных клеток и наибольшая по модулю корреляция вне диагонали, оба вводятся в тест.

### Б6. Панели гистограмм по группам
