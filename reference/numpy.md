## 1. Что такое NumPy

NumPy — библиотека Python для работы с числовыми массивами. Её основной тип данных — **массив** `ndarray`: набор элементов одного типа фиксированной длины, хранящийся в памяти одним плотным блоком. Список Python может содержать что угодно и хранит каждый элемент отдельно; массив NumPy хранит, например, только целые числа, зато знает, где лежит каждый элемент, и обрабатывает их все сразу.

Из этого устройства следуют преимущества:

- **Векторизация.** Операция записывается для всего массива, без цикла по элементам: `amounts * 0.7` вместо `[a * 0.7 for a in amounts]`. Код читается как формула.
- **Скорость.** Цикл выполняется внутри NumPy на языке C: удвоить миллион чисел списком Python занимает около 16 мс, массивом — около 0,5 мс, в тридцать раз быстрее. Для картотеки из тысячи дел разница незаметна, для миллиона записей это разница между секундой и минутой.
- **Отбор по условию.** Сравнение массива с числом даёт логический массив, который отбирает нужные элементы: `amounts[amounts > 100_000]`.
- **Статистики одной строкой.** Среднее, медиана, процентили, суммы по строкам и столбцам таблицы — методы массива.
- **Основа других библиотек.** Столбец таблицы pandas — это массив NumPy, графики Matplotlib строятся по массивам, статистические тесты SciPy принимают массивы. Всё, что умеет массив, умеет и столбец таблицы.

Цена этих преимуществ — один тип данных на массив: одно дробное число делает дробными все элементы, одна строка делает строками все. Массивы удобны для чисел; для таблиц с текстовыми столбцами, датами и пропусками с семинара 4 используется pandas.

Официальная документация: [numpy.org/doc/stable](https://numpy.org/doc/stable/): руководство для начинающих [NumPy: the absolute basics for beginners](https://numpy.org/doc/stable/user/absolute_beginners.html) и справочник по всем функциям [API reference](https://numpy.org/doc/stable/reference/index.html). Здесь собраны функции, которые нужны в курсе, и несколько соседних с ними; у функций, которых на семинарах нет, первой строкой карточки стоит «Дополнительно». В карточке функции: полная подпись в заголовке, что делает, каждый параметр с типом, обязательностью и значением по умолчанию, что возвращает, примеры в таблице с пояснением, ловушки и применение там, где они есть. Параметры, названные служебными, нужны для полноты, в курсе они не встречаются.

## 2. Подключение и вывод

### import numpy as np

Библиотека входит в окружение курса `courses` и подключается один раз в начале ноутбука под коротким именем `np`; все функции вызываются как `np.имя`. Версию показывает `np.__version__`; в курсе NumPy не ниже 2.4.

### Как читать вывод

- `array([48000, 250000])` — массив; `[48000 250000]` — тот же массив после `print`, без запятых.
- Точка на конце числа, `33600.`, означает дробный тип; `np.float64(319100.0)` — одиночное дробное число с пометкой типа, `print` напечатает `319100.0`.
- Большой массив печатается с многоточием: начало и конец, середина скрыта.
- Очень большие или очень маленькие дробные числа печатаются в записи `1.2e+06`; отключает её строка `np.set_printoptions(suppress=True)` в начале ноутбука.

### a.tolist()

Превращает массив в обычный список Python с обычными числами.

Параметров нет.

Возвращает:

- `list`: список для одномерного массива, список списков для таблицы; числа NumPy становятся `int` и `float` Python.

| Пример | Результат | Пояснение |
|---|---|---|
| `amounts[:3].tolist()` | `[48000, 250000, 1200000]` | обычный список: запятые, числа `int` |

- Применение: тесты в упражнениях сравнивают `result.tolist()` со списком; числа NumPy при этом становятся обычными `int` и `float`.

## 3. Данные для примеров

Примеры считаются на картотеке из 12 дел из упражнений семинаров 2 и 3 и на таблице нагрузки трёх судов за четыре года. Выполните эту ячейку, и любой пример справочника можно повторить у себя. Результаты показаны так, как их печатает `print`; только таблицы записаны в одну строку, а `print` выводит каждую строку таблицы с новой строки.

```python
import numpy as np

numbers  = np.arange(1, 13)                                                  # номера дел
amounts  = np.array([48_000, 250_000, 1_200_000, 75_000, 320_000, 15_000,
                     640_000, 98_000, 410_000, 135_000, 27_000, 560_000])   # цена иска, руб.
days     = np.array([60, 150, 88, 121, np.nan, 19, 45, 182, 34, np.nan, 28, 71])   # срок, дней; nan — не завершено
outcomes = np.array([1, 0, 1, 1, np.nan, 1, 1, 0, 1, np.nan, 1, 1])                 # 1 удовлетворён, 0 отказано
load = np.array([[1200, 1350, 1420, 1510],
                 [ 800,  790,  910,  880],
                 [2100, 2250, 2300, 2390]])                                  # три суда × четыре года, дел за год
```

## 4. Создание массивов

Подробно о способах создания массивов: [Array creation](https://numpy.org/doc/stable/user/basics.creation.html) в документации.

### np.array(object, dtype=None, *, copy=True, order='K', subok=False, ndmin=0, ndmax=0, like=None)

Создаёт массив из списка, кортежа или списка списков.

Параметры:

- `object` (список, кортеж, массив или вложенные списки одинаковой длины, обязательный): данные; список списков даёт таблицу, одно число даёт массив без осей.
- `dtype` (тип данных, необязательный, по умолчанию `None`): тип элементов: `int`, `float`, `str`, `bool` или точные типы NumPy `np.int64`, `np.float64`, `np.int32`; если не задан, NumPy подбирает тип, который вмещает все значения.
- `copy` (логическое или `None`, необязательный, по умолчанию `True`): при `True` данные всегда копируются, при `None` копия делается только по необходимости, при `False` NumPy выдаёт `ValueError`, если без копии не обойтись.
- `order` (`'K'`, `'A'`, `'C'` или `'F'`, необязательный, по умолчанию `'K'`): порядок хранения таблицы в памяти, по строкам или по столбцам; служебный, в курсе не нужен.
- `subok` (логическое, необязательный, по умолчанию `False`): пропускать ли подклассы массива как есть; служебный.
- `ndmin` (целое, необязательный, по умолчанию 0): наименьшее число осей результата; недостающие оси длины 1 добавляются спереди.
- `ndmax` (целое, необязательный, по умолчанию 0): наибольшая глубина разбора вложенных списков; 0 означает без ограничения; с NumPy 2.4.
- `like` (массив другой библиотеки, необязательный, по умолчанию `None`): ссылка на объект другой библиотеки, чтобы создать её массив вместо массива NumPy; в курсе не используется.

Возвращает:

- `ndarray`: массив, все элементы одного типа.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.array([1, 2, 3])` | `[1 2 3]` | из списка целых: тип `int64` |
| `np.array([1, 2, 3], dtype=float)` | `[1. 2. 3.]` | `dtype=float`: точки на конце означают дробные |
| `np.array([1, 2.5]).dtype` | `float64` | одно дробное сделало дробными все |

- Ловушка: одно дробное число делает дробными все элементы, одна строка делает строками все.

### np.arange([start, ]stop, [step, ]dtype=None, *, device=None, like=None)

Последовательность чисел от `start` до `stop` не включая `stop`, как `range`, но границы и шаг могут быть дробными.

Параметры:

- `start` (число, необязательный, по умолчанию 0): начало интервала, входит в него.
- `stop` (число, обязательный): конец интервала, не входит в него; при дробном шаге из-за погрешности округления может и войти.
- `step` (число, необязательный, по умолчанию 1): расстояние между соседними значениями, может быть отрицательным и дробным; если задан `step`, нужно задать и `start`.
- `dtype` (тип данных, необязательный, по умолчанию `None`): тип элементов; если не задан, выводится по остальным аргументам: целые аргументы дают целые, хотя бы один дробный даёт дробные.
- `device` (строка, необязательный, по умолчанию `None`): устройство, на котором создаётся массив; только для совместимости с Array API, если задано, то `"cpu"`.
- `like` (массив другой библиотеки, необязательный, по умолчанию `None`): ссылка на объект другой библиотеки, чтобы создать её массив вместо массива NumPy; в курсе не используется.

Возвращает:

- `ndarray`: одномерный массив; для целых аргументов то же, что `range`, но массивом.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.arange(5)` | `[0 1 2 3 4]` | один аргумент: от нуля, пять чисел |
| `np.arange(1, 6)` | `[1 2 3 4 5]` | от 1 до 6, шесть не входит |
| `np.arange(0, 10, 3)` | `[0 3 6 9]` | шаг 3 |
| `np.arange(30, 14, -3)` | `[30 27 24 21 18 15]` | отрицательный шаг: убывание, 14 не входит |
| `np.arange(5, dtype=float)` | `[0. 1. 2. 3. 4.]` | `dtype=float`: те же числа дробными |

- Ловушка: с дробным шагом накапливается погрешность и число элементов может отличаться от ожидаемого; для дробных сеток берите `linspace`.
- Применение: номера дел `np.arange(1, 13)`.

### np.linspace(start, stop, num=50, endpoint=True, retstep=False, dtype=None, axis=0, *, device=None)

Дополнительно: на семинарах не используется.

`num` чисел от `start` до `stop` с равными промежутками. `arange` задаёт шаг и исключает правую границу; `linspace` задаёт число точек и включает её.

Параметры:

- `start` (число или массив, обязательный): начало последовательности.
- `stop` (число или массив, обязательный): конец последовательности; входит в неё при `endpoint=True`.
- `num` (целое, необязательный, по умолчанию 50): число точек, не отрицательное.
- `endpoint` (логическое, необязательный, по умолчанию `True`): включать ли `stop`; при `True` промежутков между точками `num - 1`, при `False` промежутков `num`, и шаг меньше.
- `retstep` (логическое, необязательный, по умолчанию `False`): при `True` вернуть пару: массив и шаг.
- `dtype` (тип данных, необязательный, по умолчанию `None`): тип элементов; если не задан, выводится по `start` и `stop`, для целых границ всё равно дробный.
- `axis` (целое, необязательный, по умолчанию 0): если `start` и `stop` массивы одинаковой формы, ось результата, вдоль которой идут точки.
- `device` (строка, необязательный, по умолчанию `None`): устройство, на котором создаётся массив; только для совместимости с Array API, если задано, то `"cpu"`.

Возвращает:

- `ndarray`: массив из `num` дробных чисел; при `retstep=True` кортеж из массива и шага (`float`).

| Пример | Результат | Пояснение |
|---|---|---|
| `np.linspace(0, 1, 5)` | `[0. 0.25 0.5 0.75 1.]` | пять точек, обе границы входят |
| `np.linspace(0, 1, 5, endpoint=False)` | `[0. 0.2 0.4 0.6 0.8]` | `endpoint=False`: правая граница исключена, шаг стал 0.2 |
| `np.linspace(0, 1, 5, retstep=True)[1]` | `0.25` | `retstep=True`: второй элемент пары — шаг |
| `np.linspace(0, 100, 3)` | `[0. 50. 100.]` | три точки: начало, середина, конец |

Отличия от `arange`:

| Особенность | `linspace` | `arange` |
|---|---|---|
| Что задаётся | число точек | шаг |
| Правая граница | входит; при `endpoint=False` нет | не входит |
| Дробные сетки | без накопления погрешности | погрешность накапливается |
| Когда брать | важно число точек | важен шаг |

- Применение: сетка значений для графиков на семинарах 8–9 и для шкал, например ставки от 0 до 100 % с шагом в четверть.

### np.zeros(shape, dtype=None, order='C', *, device=None, like=None), np.ones(…), np.full(shape, fill_value, …)

Дополнительно: `ones` и `full` на семинарах не используются.

Массив заданной формы из нулей, единиц или одинаковых значений. У `np.ones` параметры те же, что у `np.zeros`; у `np.full(shape, fill_value, dtype=None, order='C', *, device=None, like=None)` добавляется значение заполнения.

Параметры:

- `shape` (целое или кортеж целых, обязательный): форма массива: число элементов или `(строки, столбцы)` для таблицы.
- `fill_value` (число, строка или логическое, обязательный, только у `full`): значение, которым заполняется массив.
- `dtype` (тип данных, необязательный, по умолчанию `None`): тип элементов; у `zeros` и `ones` без него дробный `float64`, у `full` тип берётся по `fill_value`.
- `order` (`'C'` или `'F'`, необязательный, по умолчанию `'C'`): порядок хранения таблицы в памяти, по строкам или по столбцам; служебный.
- `device` (строка, необязательный, по умолчанию `None`): устройство, на котором создаётся массив; только для совместимости с Array API, если задано, то `"cpu"`.
- `like` (массив другой библиотеки, необязательный, по умолчанию `None`): ссылка на объект другой библиотеки, чтобы создать её массив вместо массива NumPy; в курсе не используется.

Возвращает:

- `ndarray` заданной формы.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.zeros(3)` | `[0. 0. 0.]` | три нуля, по умолчанию дробные |
| `np.zeros(3, dtype=int)` | `[0 0 0]` | `dtype=int`: целые нули |
| `np.full(3, 4000)` | `[4000 4000 4000]` | три одинаковых значения, тип по значению |

- `np.full((2, 2), np.nan)` — таблица два на два из пропусков.
- Применение: заготовка под значения, которые заполняются по маскам, как пошлины в упражнении В1 семинара 2.

### np.append(arr, values, axis=None)

Добавляет элементы в конец массива.

Параметры:

- `arr` (массив или список, обязательный): исходный массив; не меняется.
- `values` (число, список или массив, обязательный): что добавить; при `axis=None` любой формы, иначе той же формы, что `arr`, кроме оси `axis`.
- `axis` (целое, необязательный, по умолчанию `None`): ось, вдоль которой добавлять; при `None` оба массива вытягиваются в одну строку; для таблиц `axis=0` добавляет строки, `axis=1` столбцы.

Возвращает:

- `ndarray`: новый массив; исходный не меняется.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.append(np.array([1, 2]), 3)` | `[1 2 3]` | добавлено одно число |
| `np.append(np.array([1, 2]), [3, 4])` | `[1 2 3 4]` | добавлен список целиком |

- Ловушка: результат нужно присвоить, `np.append` ничего не меняет на месте.

### np.concatenate(arrays, /, axis=0, out=None, *, dtype=None, casting='same_kind')

Дополнительно: на семинарах не используется.

Соединяет несколько массивов в один.

Параметры:

- `arrays` (список или кортеж массивов, обязательный): что соединять; формы должны совпадать по всем осям, кроме `axis`.
- `axis` (целое или `None`, необязательный, по умолчанию 0): ось соединения; для таблиц 0 ставит одну под другой, 1 бок о бок; при `None` массивы сначала вытягиваются в одну строку.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив нужной формы, куда записать результат; служебный, в курсе не нужен.
- `dtype` (тип данных, необязательный, по умолчанию `None`): тип результата; нельзя вместе с `out`.
- `casting` (`'no'`, `'equiv'`, `'safe'`, `'same_kind'` или `'unsafe'`, необязательный, по умолчанию `'same_kind'`): какие преобразования типов разрешены при соединении; служебный.

Возвращает:

- `ndarray`: новый массив.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.concatenate([np.array([1, 2]), np.array([3])])` | `[1 2 3]` | два массива из списка стали одним |

- Для двух массивов то же, что `np.append(a, b)`; для трёх и более удобнее `concatenate`.

## 5. Устройство массива

### a.dtype

Атрибут массива, параметров нет, читается без скобок. Тип элементов массива: `int64` целые, `float64` дробные, `bool` логические, `<U3` строки, где число — длина самой длинной строки. Число в названии — разрядность: `int64` хранит целые до девяти квинтиллионов, `int32` — до двух миллиардов и вдвое экономнее по памяти; для картотеки разница не важна, для миллионов записей тип выбирают сознательно.

Возвращает:

- `np.dtype`: объект типа; в сравнении ведёт себя как строка, `amounts.dtype == 'int64'` даёт `True`.

| Пример | Результат | Пояснение |
|---|---|---|
| `amounts.dtype` | `int64` | целые: цены заданы без точки |
| `days.dtype` | `float64` | дробные: в массиве есть `nan` |
| `np.array(['А40', 'А56']).dtype` | `<U3` | строки длиной до трёх символов |

- Ловушка: число, не помещающееся в тип, NumPy 2 не обрезает, а выдаёт `OverflowError`, например `np.array([50_000], dtype=np.int16)`, предел которого 32 767.

### a.astype(dtype, order='K', casting='unsafe', subok=True, copy=True)

Новый массив с другим типом элементов.

Параметры:

- `dtype` (тип данных, обязательный): новый тип: `int`, `float`, `str`, `bool` или точный тип NumPy.
- `order` (`'C'`, `'F'`, `'A'` или `'K'`, необязательный, по умолчанию `'K'`): порядок хранения результата в памяти; служебный.
- `casting` (`'no'`, `'equiv'`, `'safe'`, `'same_kind'`, `'same_value'` или `'unsafe'`, необязательный, по умолчанию `'unsafe'`): какие преобразования разрешить; по умолчанию любые, поэтому дробная часть молча отбрасывается; `'same_value'`, с NumPy 2.4, выдаёт ошибку, если значение изменилось бы.
- `subok` (логическое, необязательный, по умолчанию `True`): сохранять ли подкласс массива; служебный.
- `copy` (логическое, необязательный, по умолчанию `True`): при `True` всегда новый массив; при `False` и совпадающем типе возвращается сам массив.

Возвращает:

- `ndarray`: новый массив; исходный не меняется.

| Пример | Результат | Пояснение |
|---|---|---|
| `amounts[:3].astype(float)` | `[48000. 250000. 1200000.]` | целые стали дробными: точка на конце |
| `np.array([4.9, 5.5]).astype(int)` | `[4 5]` | 4.9 стало 4: дробная часть отброшена |

- Ловушка: `astype(int)` не округляет; перед ним нужно `np.round`.

### a.shape, a.ndim, a.size, len(a)

Форма, число осей, число элементов, число строк. Атрибуты читаются без скобок, параметров у них нет; `len` — встроенная функция Python.

Возвращают:

- `shape`: кортеж с числом элементов по каждой оси: `(12,)` у столбца, `(3, 4)` у таблицы.
- `ndim`: целое, число осей: 1 у столбца, 2 у таблицы.
- `size`: целое, общее число элементов.
- `len(a)`: целое, длина первой оси; у таблицы число строк.

| Пример | Результат | Пояснение |
|---|---|---|
| `amounts.shape` | `(12,)` | одна ось: кортеж из одного числа |
| `amounts.size` | `12` | число элементов |
| `load.shape` | `(3, 4)` | таблица: три строки, четыре столбца |

### a.copy(order='C')

Независимая копия массива. Функция `np.copy(a, order='K', subok=False)` делает то же.

Параметры:

- `order` (`'C'`, `'F'`, `'A'` или `'K'`, необязательный, по умолчанию `'C'`): порядок хранения копии в памяти; служебный.

Возвращает:

- `ndarray`: новый массив в отдельной памяти.

| Пример | Результат | Пояснение |
|---|---|---|
| `a = np.array([1, 2, 3]); part = a[:2]; part[0] = 99; a` | `[99 2 3]` | срез — вид на те же данные: запись в срез изменила `a` |
| `a = np.array([1, 2, 3]); part = a[:2].copy(); part[0] = 99; a` | `[1 2 3]` | запись в копию не тронула `a` |

- Применение: перед изменением массива, полученного срезом или переданного в функцию.

## 6. Арифметика и сравнения

### Арифметика с числом и с массивом

Операции `+`, `-`, `*`, `/`, `**` выполняются поэлементно: массив с числом — к каждому элементу, два массива одной длины — попарно.

| Пример | Результат | Пояснение |
|---|---|---|
| `amounts[:3] / 1000` | `[48. 250. 1200.]` | цены в тысячах; деление даёт дробные |
| `amounts[:3] * 0.7` | `[33600. 175000. 840000.]` | 70 % от каждой цены |

- Ловушка: массивы разной длины дают `ValueError: operands could not be broadcast together with shapes (12,) (3,)`; в сообщении названы обе формы.

### round(number, ndigits=None), np.round(a, decimals=0, out=None), a.round(decimals=0, out=None)

Округление: `round` для одного числа, `np.round` и метод `round` для массива. Половина округляется к ближайшему чётному, и у NumPy, и у Python: `2.5` даёт `2`.

Параметры:

- `number` (число, обязательный) и `ndigits` (целое, необязательный, по умолчанию `None`): у встроенной `round`; без `ndigits` результат целое, с `ndigits` дробное с указанным числом знаков.
- `a` (массив или число, обязательный): что округлять.
- `decimals` (целое, необязательный, по умолчанию 0): число знаков после запятой; отрицательное округляет до десятков, сотен и так далее.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив нужной формы, куда записать результат; служебный, в курсе не нужен.

Возвращает:

- `round`: `int` без `ndigits`, иначе `float`; `np.round` и `a.round`: массив того же типа, дробный остаётся дробным, `[1200.]`, а не `[1200]`.

| Пример | Результат | Пояснение |
|---|---|---|
| `round(amounts.mean())` | `314833` | одно число до целого |
| `np.round(amounts[:3] / 1000, 1)` | `[48. 250. 1200.]` | массив до одного знака после запятой |
| `np.round(np.array([1234.5678]), -2)` | `[1200.]` | `decimals=-2`: до сотен |
| `np.round(np.array([0.5, 1.5, 2.5]))` | `[0. 2. 2.]` | половина округляется к чётному |

### Математические функции: np.abs(x), np.sqrt(x), np.log(x), np.log10(x), np.exp(x)

Дополнительно: на семинарах не используются.

Модуль, квадратный корень, натуральный и десятичный логарифм, экспонента; все поэлементно. Константа `np.pi` — число π. Все пять — универсальные функции с одинаковой подписью `np.sqrt(x, /, out=None, *, where=True, casting='same_kind', order='K', dtype=None, subok=True, signature=None)`.

Параметры:

- `x` (массив или число, обязательный): аргумент; только позиционный.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив нужной формы, куда записать результат; служебный, в курсе не нужен.
- `where` (логический массив, необязательный, по умолчанию `True`): где вычислять; остальные элементы результата остаются как в `out`.
- `casting`, `order`, `dtype`, `subok`, `signature` (необязательные): правила преобразования типов, порядок в памяти, тип результата, подклассы и точная сигнатура; общие для всех универсальных функций, в курсе не нужны.

Возвращает:

- `ndarray` той же формы: `abs` сохраняет тип, остальные дают дробные; для одного числа `np.float64`.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.abs(np.array([-3, 2]))` | `[3 2]` | модуль: знак убран |
| `np.sqrt(np.array([16, 25]))` | `[4. 5.]` | корень всегда дробный |
| `np.log10(np.array([10, 1000]))` | `[1. 3.]` | десятичный логарифм: порядок числа |

- Применение: логарифм цен исков сжимает разброс от тысяч до миллионов, пригодится на семинарах о графиках и нормальности.

### Сравнения и логические массивы

`>`, `>=`, `<`, `<=`, `==`, `!=` сравнивают поэлементно и дают массив из `True` и `False` — маску.

| Пример | Результат | Пояснение |
|---|---|---|
| `amounts[:3] > 100_000` | `[False True True]` | маска: `True` напротив подходящих цен |

- Условия соединяются `&` (и), `|` (или), `~` (не), каждое условие в скобках.

| Пример | Результат | Пояснение |
|---|---|---|
| `((amounts > 100_000) & (outcomes == 1)).sum()` | `4` | дорогих и удовлетворённых дел; каждое условие в скобках |

- Ловушка: `and`, `or`, `not` и условие без скобок дают `ValueError: The truth value of an array with more than one element is ambiguous`.

### np.isin(element, test_elements, assume_unique=False, invert=False, *, kind=None)

Дополнительно: на семинарах не используется.

Маска элементов, которые входят в список значений.

Параметры:

- `element` (массив, обязательный): что проверять.
- `test_elements` (список или массив, обязательный): допустимые значения; вытягивается в одну строку.
- `assume_unique` (логическое, необязательный, по умолчанию `False`): при `True` оба массива считаются без повторов, что ускоряет расчёт.
- `invert` (логическое, необязательный, по умолчанию `False`): при `True` маска перевёрнута: `True` у элементов, которых нет в списке.
- `kind` (`None`, `'sort'` или `'table'`, необязательный, по умолчанию `None`): алгоритм; влияет только на скорость и память.

Возвращает:

- `ndarray` логический той же формы, что `element`.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.isin(np.array(['договор', 'трудовой', 'неустойка']), ['договор', 'неустойка'])` | `[True False True]` | `True` у категорий из списка |

- Применение: отобрать дела нескольких категорий сразу вместо цепочки `|`.

### np.clip(a, a_min=None, a_max=None, out=None, *, min=None, max=None, **kwargs)

Дополнительно: на семинарах не используется.

Ограничивает значения снизу и сверху: всё меньше `a_min` становится `a_min`, всё больше `a_max` — `a_max`.

Параметры:

- `a` (массив, обязательный): что ограничивать.
- `a_min`, `a_max` (число, массив или `None`, необязательные): нижняя и верхняя границы; `None` снимает границу с этой стороны.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив для результата; может быть самим `a`, тогда обрезка идёт на месте.
- `min`, `max` (число, массив или `None`, только по имени, необязательные, по умолчанию `None`): те же границы под именами Array API, с NumPy 2.1; задаются либо они, либо `a_min` и `a_max`.
- `**kwargs`: параметры универсальных функций вроде `where`; в курсе не нужны.

Возвращает:

- `ndarray`: новый массив той же формы.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.clip(amounts[:3], 0, 400_000)` | `[48000 250000 400000]` | 1 200 000 срезано до верхней границы |

- То же, что копия с присваиванием по маске из упражнения Б6 семинара 2, одной строкой.

### np.cumsum(a, axis=None, dtype=None, out=None), np.diff(a, n=1, axis=-1, prepend=<no value>, append=<no value>)

Дополнительно: на семинарах не используются.

Нарастающий итог и разности соседних элементов.

Параметры:

- `a` (массив, обязательный): исходные значения.
- `axis` (целое или `None`, необязательный): ось; у `cumsum` по умолчанию `None`, массив вытягивается в строку; у `diff` по умолчанию `-1`, последняя ось, то есть вдоль строки таблицы.
- `dtype` (тип данных, необязательный, по умолчанию `None`): у `cumsum` тип накопителя и результата.
- `out` (массив, необязательный, по умолчанию `None`): у `cumsum` готовый массив нужной формы, куда записать результат; служебный, в курсе не нужен.
- `n` (целое, необязательный, по умолчанию 1): у `diff` сколько раз брать разности; 0 возвращает массив как есть.
- `prepend`, `append` (число или массив, необязательные): у `diff` значения, приписываемые к началу или к концу перед взятием разностей, чтобы результат не укорачивался.

Возвращает:

- `cumsum`: массив той же длины; `diff`: массив короче на `n` элементов.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.cumsum(np.array([100, 200, 300]))` | `[100 300 600]` | сумма от начала до каждого элемента |
| `np.diff(np.array([100, 130, 120]))` | `[30 -10]` | прирост и спад; на элемент короче |

- Применение: число дел нарастающим итогом по месяцам; прирост к предыдущему году — `np.diff(cases) / cases[:-1] * 100`.

### np.array_equal(a1, a2, equal_nan=False), np.allclose(a, b, rtol=1e-05, atol=1e-08, equal_nan=False)

Сравнение массивов целиком: точное и с допуском на погрешность дробной арифметики.

Параметры:

- `a1`, `a2` у `array_equal` и `a`, `b` у `allclose` (массивы или числа, обязательные): что сравнивать; у `array_equal` должны совпасть и формы, `allclose` подгоняет формы друг к другу, как арифметика.
- `rtol` (число, необязательный, по умолчанию `1e-05`): относительный допуск, доля от `|b|`.
- `atol` (число, необязательный, по умолчанию `1e-08`): абсолютный допуск; элементы равны, если `|a - b| <= atol + rtol * |b|`.
- `equal_nan` (логическое, необязательный, по умолчанию `False`): считать ли два `nan` равными.

Возвращает:

- `bool`: одно значение на весь массив.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.array_equal(np.array([1, 2]), np.array([1, 2]))` | `True` | одно `True` на весь массив, не поэлементно |
| `np.allclose(0.1 + 0.2, 0.3)` | `True` | `==` дало бы `False`: сумма равна 0.30000000000000004 |

- Применение: тесты упражнений; `==` для массивов даёт массив, а не один ответ.

## 7. Индексация, срезы, маски

Подробно об индексации: [Indexing on ndarrays](https://numpy.org/doc/stable/user/basics.indexing.html) в документации.

### Элемент и срез

- `a[i]` — элемент, нумерация с нуля; `a[-1]` — последний; `a[i:j]` — с `i` до `j` не включая `j`; `a[i:j:k]` — с шагом `k`; `a[::-1]` — в обратном порядке.

| Пример | Результат | Пояснение |
|---|---|---|
| `amounts[0]` | `48000` | первый элемент, индекс 0 |
| `amounts[-1]` | `560000` | последний элемент |
| `amounts[2:5]` | `[1200000 75000 320000]` | индексы 2, 3, 4; пятый не входит |
| `amounts[::4]` | `[48000 320000 410000]` | каждый четвёртый, начиная с первого |
| `amounts[-3:]` | `[135000 27000 560000]` | три последних |

- Ловушка: `a[-k:]` при `k = 0` даёт весь массив, потому что `-0` это `0`; проверяйте этот случай отдельно.
- Срез — вид на те же данные: `part = a[:2]; part[0] = 99` меняет `a`. Копия — `a[:2].copy()`.

### Маска

Логический массив в квадратных скобках оставляет элементы напротив `True`. Маска по одному массиву отбирает элементы другого массива той же длины.

| Пример | Результат | Пояснение |
|---|---|---|
| `amounts[amounts > 500_000]` | `[1200000 640000 560000]` | цены дороже 500 000 |
| `numbers[amounts > 500_000]` | `[3 7 12]` | номера тех же дел: маска по другому массиву |
| `(amounts > 100_000).sum()` | `7` | число `True`: дел дороже 100 000 |
| `round((amounts > 100_000).mean(), 2)` | `0.58` | их доля среди двенадцати дел |

- Присваивание по маске меняет только отмеченные элементы: `capped = amounts.copy(); capped[capped > 400_000] = 400_000`. Так же работают `+=`, `-=`, `*=`: `capped[capped < 50_000] += 1_000` увеличивает только мелкие суммы.

### mask.any(axis=None, out=None, keepdims=False, *, where=True), mask.all(…)

Есть ли в маске хотя бы одно `True`; все ли `True`. Одно значение вместо массива — то, чего требует `if`. У `all` параметры те же; функции `np.any(a, …)` и `np.all(a, …)` делают то же.

Параметры:

- `axis` (целое, кортеж или `None`, необязательный, по умолчанию `None`): ось для таблицы: `axis=0` даёт по одному числу на столбец, `axis=1` на строку; без него по всему массиву.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив нужной формы, куда записать результат; служебный, в курсе не нужен.
- `keepdims` (логическое, необязательный, по умолчанию `False`): сохранять ли свёрнутую ось длиной 1, чтобы результат подставлялся обратно в таблицу.
- `where` (логический массив, только по имени, необязательный, по умолчанию `True`): какие элементы учитывать.

Возвращает:

- одно логическое значение; с `axis` логический массив.

| Пример | Результат | Пояснение |
|---|---|---|
| `(amounts > 1_000_000).any()` | `True` | хотя бы одно дело дороже миллиона |
| `(amounts > 20_000).all()` | `False` | не все дороже 20 000: есть 15 000 |
| `np.isnan(days).any()` | `True` | есть хотя бы один пропуск |

- Применение: `if np.isnan(days).any():` — проверить, есть ли пропуски; тесты упражнений проверяют так, что в результате не осталось `nan`.

### Индексация массивом индексов

Массив или список целых чисел в квадратных скобках выбирает элементы по номерам позиций и в заданном порядке; так же можно присваивать. В курсе используется в двух местах: индексы от `argsort` подставляются в массив номеров, а пропуски записываются по массиву индексов незавершённых дел.

| Пример | Результат | Пояснение |
|---|---|---|
| `amounts[[0, 2]]` | `[48000 1200000]` | элементы с позиций 0 и 2 |
| `amounts[[0, 0, 2]]` | `[48000 48000 1200000]` | индексы могут повторяться |
| `numbers[np.argsort(amounts)[::-1][:3]]` | `[3 7 12]` | номера трёх самых дорогих дел |

- Присваивание: `unfinished = np.array([4, 9]); days[unfinished] = np.nan` — сроки двух дел стали пропусками.
- Согласованное перемешивание нескольких массивов: `idx = rng.permutation(len(amounts))`, затем `amounts[idx]` и `days[idx]` перемешаны одинаково, и дела не перепутались.
- Ловушка: индексы — позиции с нуля, а не номера дел; номер дела 3 стоит на позиции 2.

## 8. Таблицы: двумерные массивы

Таблица — массив с двумя осями: ось 0 идёт по строкам, ось 1 по столбцам. В картотеке строка — дело, столбец — поле; в таблице нагрузки строка — суд, столбец — год. Всё, что умеет одномерный массив, умеет и таблица; добавляются только выбор строки или столбца и параметр `axis`.

### Создание таблицы

- Из списка списков одинаковой длины; из нулей заданной формы; из столбцов через `np.column_stack([a, b])`, где `a` и `b` — массивы одной длины; на семинарах эта функция не используется.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.array([[1, 2], [3, 4]])` | `[[1 2] [3 4]]` | из списка списков |
| `np.zeros((2, 3))` | `[[0. 0. 0.] [0. 0. 0.]]` | форма кортежем: две строки, три столбца |
| `np.column_stack([numbers[:2], amounts[:2]])` | `[[1 48000] [2 250000]]` | столбцы: номер дела и цена иска |
- Из строк: `np.array([amounts, days, outcomes]).T` — три массива становятся строками, `.T` превращает их в столбцы.
- Ловушка: у всех столбцов таблицы один тип; если добавить дробный столбец, например `days` с пропусками, дробными станут и номера дел, и цены, а большие числа напечатаются в записи вида `4.8e+04`.

### Форма, строка, столбец, элемент

| Пример | Результат | Пояснение |
|---|---|---|
| `load.shape` | `(3, 4)` | три строки, четыре столбца |
| `len(load)` | `3` | число строк |
| `load[0]` | `[1200 1350 1420 1510]` | строка: первый суд |
| `load[:, 1]` | `[1350 790 2250]` | столбец: второй год у всех судов |
| `load[1, 2]` | `910` | элемент: второй суд, третий год |
| `load[:2, 1:3]` | `[[1350 1420] [790 910]]` | блок: первые два суда, второй и третий годы |

- Двоеточие означает «все»; первый индекс всегда строка, второй столбец.

### Строки по условию на столбец

Маска по столбцу отбирает строки таблицы целиком.

| Пример | Результат | Пояснение |
|---|---|---|
| `load[load[:, 0] > 1000]` | `[[1200 1350 1420 1510] [2100 2250 2300 2390]]` | суды, у которых в первый год больше 1000 дел |
| `load[:, 3][load[:, 0] > 1000]` | `[1510 2390]` | их нагрузка в последний год |
| `load[load > 2000]` | `[2100 2250 2300 2390]` | маска по всей таблице: плоский массив элементов, не строки |

- Ловушка: чтобы отобрать строки, маска строится по одному столбцу, как `load[:, 0] > 1000`, а не по всей таблице.

### Сортировка строк по столбцу

`argsort` по столбцу даёт порядок строк; массив индексов в квадратных скобках переставляет строки.

| Пример | Результат | Пояснение |
|---|---|---|
| `load[np.argsort(load[:, 3])[::-1]]` | `[[2100 2250 2300 2390] [1200 1350 1420 1510] [800 790 910 880]]` | суды по убыванию нагрузки в последний год |

### Статистики по осям

`sum`, `mean`, `min`, `max`, `median` и остальные принимают `axis`: `axis=0` — вдоль строк, по одному числу на столбец; `axis=1` — вдоль столбцов, по одному числу на строку; без `axis` — по всей таблице.

| Пример | Результат | Пояснение |
|---|---|---|
| `load.sum(axis=0)` | `[4100 4390 4630 4780]` | дел за каждый год по всем судам |
| `load.mean(axis=1)` | `[1370. 845. 2260.]` | среднее в год у каждого суда |
| `load.max(axis=1)` | `[1510 910 2390]` | самый нагруженный год каждого суда |
| `load.sum()` | `17900` | без `axis`: все дела всех судов за все годы |

- Ловушка: складывать столбцы разного смысла бессмысленно; `axis` нужен для однородных таблиц вроде нагрузки, а не для картотеки с ценой, сроком и исходом.

### Поиск в таблице

| Пример | Результат | Пояснение |
|---|---|---|
| `load.argmax(axis=1)` | `[3 2 3]` | номер года с максимумом у каждого суда: у второго суда пик в третий год |
| `load.argmax(axis=0)` | `[2 2 2 2]` | номер суда с максимумом в каждый год |
| `np.argmax(load)` | `11` | без `axis`: позиция в таблице, вытянутой в одну строку |

- Строку и столбец из плоской позиции даёт `np.unravel_index(11, load.shape)`, но проще сразу указать `axis`.

### Таблица и вектор

Таблица с числом — поэлементно; таблица с массивом длиной в число столбцов — массив применяется к каждой строке.

| Пример | Результат | Пояснение |
|---|---|---|
| `load - load.min(axis=0)` | `[[400 560 510 630] [0 0 0 0] [1300 1460 1390 1510]]` | на сколько дел больше, чем у самого незагруженного суда в тот год |
| `np.round(load / load.sum(axis=0) * 100)[0]` | `[29. 31. 31. 32.]` | доля первого суда в делах каждого года, % |

- Ловушка: массив длиной в число строк к таблице так не применить: NumPy сообщит о несовместимых формах `(3, 4)` и `(3,)`.

### a.T, a.reshape(shape, /, *, order='C', copy=None), np.vstack(tup, *, dtype=None, casting='same_kind'), np.hstack(…)

Дополнительно: `reshape`, `vstack` и `hstack` на семинарах не используются.

Транспонирование, смена формы и склейка таблиц. У `np.hstack` параметры те же, что у `np.vstack`.

Параметры:

- `T`: атрибут без параметров; строки и столбцы меняются местами, данные не копируются.
- `shape` (целое или кортеж целых, обязательный): новая форма; число элементов должно совпасть, один из размеров может быть `-1`, тогда он вычисляется; можно писать `a.reshape(2, 3)` без кортежа.
- `order` (`'C'`, `'F'` или `'A'`, необязательный, по умолчанию `'C'`): в каком порядке читать и раскладывать элементы: по строкам или по столбцам.
- `copy` (логическое или `None`, необязательный, по умолчанию `None`): при `None` копия делается только если без неё нельзя, при `True` всегда, при `False` ошибка, если без копии не обойтись.
- `tup` (список или кортеж массивов, обязательный): что склеивать; у `vstack` должно совпадать число столбцов, у `hstack` число строк.
- `dtype` (тип данных, только по имени, необязательный, по умолчанию `None`): тип результата склейки.
- `casting` (строка, только по имени, необязательный, по умолчанию `'same_kind'`): разрешённые преобразования типов; служебный.

Возвращает:

- `T` и `reshape`: вид на те же данные, когда это возможно; `vstack` и `hstack`: новый массив.

| Пример | Результат | Пояснение |
|---|---|---|
| `load.T.shape` | `(4, 3)` | строки и столбцы поменялись местами |
| `np.arange(6).reshape(2, 3)` | `[[0 1 2] [3 4 5]]` | те же шесть элементов в форме 2 × 3 |
| `np.vstack([load, [900, 950, 980, 1000]]).shape` | `(4, 4)` | добавить строку: четвёртый суд |
| `np.column_stack([load, load.sum(axis=1)])[0]` | `[1200 1350 1420 1510 5480]` | добавить столбец: итог по суду |

- У `reshape` число элементов должно совпадать с формой; `-1` вместо одного из размеров вычисляется само.
- `np.hstack([a, b])` ставит две таблицы бок о бок, как `column_stack` столбцы.
- Обход строк в цикле: `for row in load:` даёт по одной строке; чаще нужнее векторная запись без цикла.

## 9. Статистики

### a.sum(axis=None, dtype=None, out=None, keepdims=False, initial=0, where=True), a.mean(…), a.min(…), a.max(…)

Сумма, среднее, минимум и максимум; есть и как функции `np.sum(a, …)`, `np.mean(a, …)`, `np.min(a, …)`, `np.max(a, …)` с теми же параметрами после `a`. У `mean` нет `initial`, у `min` и `max` нет `dtype`.

Параметры:

- `axis` (целое, кортеж или `None`, необязательный, по умолчанию `None`): ось для таблицы: `axis=0` даёт по одному числу на столбец, `axis=1` на строку; без него по всему массиву.
- `dtype` (тип данных, необязательный, по умолчанию `None`): тип накопителя и результата; у `mean` для целых массивов по умолчанию `float64`.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив нужной формы, куда записать результат; служебный, в курсе не нужен.
- `keepdims` (логическое, необязательный, по умолчанию `False`): сохранять ли свёрнутую ось длиной 1, чтобы результат подставлялся обратно в таблицу.
- `initial` (число, необязательный): у `sum` начальное значение, по умолчанию 0; у `min` и `max` значение, с которым сравнивается результат, обязательно для пустого массива.
- `where` (логический массив, необязательный, по умолчанию `True`): какие элементы учитывать.

Возвращает:

- число, `np.int64` или `np.float64`; с `axis` массив.

| Пример | Результат | Пояснение |
|---|---|---|
| `amounts.sum()` | `3778000` | общая цена всех исков |
| `amounts.max()` | `1200000` | самый дорогой иск |
| `round(amounts.mean())` | `314833` | средняя цена, округлена до рубля |

- Среднее массива из нулей и единиц — доля единиц; сумма маски — число `True`.

### np.median(a, axis=None, out=None, overwrite_input=False, keepdims=False)

Медиана: значение посередине упорядоченного массива, половина элементов меньше, половина больше. При чётном числе элементов — среднее двух средних.

Параметры:

- `a` (массив, обязательный): значения.
- `axis` (целое, кортеж или `None`, необязательный, по умолчанию `None`): ось для таблицы: `axis=0` даёт по одному числу на столбец, `axis=1` на строку; без него по всему массиву.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив нужной формы, куда записать результат; служебный, в курсе не нужен.
- `overwrite_input` (логическое, необязательный, по умолчанию `False`): разрешить портить `a` промежуточной сортировкой ради экономии памяти; после этого содержимое `a` не определено.
- `keepdims` (логическое, необязательный, по умолчанию `False`): сохранять ли свёрнутую ось длиной 1, чтобы результат подставлялся обратно в таблицу.

Возвращает:

- `np.float64`; с `axis` массив.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.median(amounts)` | `192500.0` | среднее двух средних цен: 135 000 и 250 000 |

- Ловушка: метода `amounts.median()` нет, только функция; при `nan` в массиве результат `nan`, нужна `np.nanmedian`.

### a.std(axis=None, dtype=None, out=None, ddof=0, keepdims=False, *, where=True), a.var(…)

Дополнительно: `var` на семинарах не используется.

Стандартное отклонение — типичное отклонение от среднего; дисперсия — его квадрат. У `var` параметры те же; функции `np.std(a, …)` и `np.var(a, …)` принимают ещё `mean` и `correction`.

Параметры:

- `axis` (целое, кортеж или `None`, необязательный, по умолчанию `None`): ось для таблицы: `axis=0` даёт по одному числу на столбец, `axis=1` на строку; без него по всему массиву.
- `dtype` (тип данных, необязательный, по умолчанию `None`): тип расчёта; для целых массивов по умолчанию `float64`.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив нужной формы, куда записать результат; служебный, в курсе не нужен.
- `ddof` (целое, необязательный, по умолчанию 0): поправка знаменателя: делитель равен числу элементов минус `ddof`; `0` описывает сами данные, `1` оценивает разброс совокупности по выборке.
- `keepdims` (логическое, необязательный, по умолчанию `False`): сохранять ли свёрнутую ось длиной 1, чтобы результат подставлялся обратно в таблицу.
- `where` (логический массив, только по имени, необязательный, по умолчанию `True`): какие элементы учитывать.
- `mean` (число или массив, только у `np.std` и `np.var`, необязательный): заранее посчитанное среднее, чтобы не считать его снова.
- `correction` (целое, только у `np.std` и `np.var`, необязательный): то же, что `ddof`, под именем Array API; задаётся один из двух.

Возвращает:

- `np.float64`; с `axis` массив.

| Пример | Результат | Пояснение |
|---|---|---|
| `round(amounts.std())` | `334598` | `ddof=0`: делитель 12 |
| `round(amounts.std(ddof=1))` | `349476` | `ddof=1`: делитель 11, оценка чуть больше |

- Чем больше отклонение относительно среднего, тем сильнее разброс: здесь разброс цен сравним со средней ценой. Какой `ddof` когда нужен — на семинарах 11–13; pandas по умолчанию считает с `ddof=1`.

### np.percentile(a, q, axis=None, out=None, overwrite_input=False, method='linear', keepdims=False, *, weights=None), np.quantile(…)

Дополнительно: `quantile` на семинарах не используется.

Процентиль: значение, ниже которого лежит `q` процентов элементов; квантиль — то же в долях от 0 до 1. 50-й процентиль — медиана, 25-й и 75-й — квартили. У `quantile` параметры те же.

Параметры:

- `a` (массив, обязательный): значения.
- `q` (число или список чисел, обязательный): процентиль от 0 до 100; у `quantile` доля от 0 до 1.
- `axis` (целое, кортеж или `None`, необязательный, по умолчанию `None`): ось для таблицы: `axis=0` даёт по одному числу на столбец, `axis=1` на строку; без него по всему массиву.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив нужной формы, куда записать результат; служебный, в курсе не нужен.
- `overwrite_input` (логическое, необязательный, по умолчанию `False`): разрешить портить `a` промежуточной сортировкой ради экономии памяти.
- `method` (строка, необязательный, по умолчанию `'linear'`): как считать значение между соседними наблюдениями: `'linear'` — линейная интерполяция, так же считает pandas; `'lower'`, `'higher'`, `'nearest'`, `'midpoint'` берут соседние наблюдения; ещё восемь способов из статистической литературы описаны в документации.
- `keepdims` (логическое, необязательный, по умолчанию `False`): сохранять ли свёрнутую ось длиной 1, чтобы результат подставлялся обратно в таблицу.
- `weights` (массив, только по имени, необязательный, по умолчанию `None`): веса наблюдений; работают только с `method='inverted_cdf'`.

Возвращает:

- `np.float64`; для списка `q` массив.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.percentile(amounts, 25)` | `68250.0` | четверть дел дешевле; между третьей и четвёртой ценой |
| `np.percentile(amounts, [25, 50, 75])` | `[68250. 192500. 447500.]` | список `q`: три квартиля одним вызовом |
| `np.quantile(amounts, 0.5)` | `192500.0` | доля 0.5: та же медиана |
| `np.percentile(amounts, 75) - np.percentile(amounts, 25)` | `379250.0` | межквартильный размах: правило выбросов на семинаре 10 |

- Ловушка: при `nan` в массиве результат `nan`, нужна `np.nanpercentile`.

### np.unique(ar, return_index=False, return_inverse=False, return_counts=False, axis=None, *, equal_nan=True, sorted=True)

Дополнительно: на семинарах не используется.

Уникальные значения массива, по возрастанию; с `return_counts=True` ещё и сколько раз каждое встречается.

Параметры:

- `ar` (массив чисел или строк, обязательный): значения; без `axis` вытягивается в строку.
- `return_index` (логическое, необязательный, по умолчанию `False`): вернуть ещё позиции первых вхождений.
- `return_inverse` (логическое, необязательный, по умолчанию `False`): вернуть ещё позиции, по которым из уникальных значений восстанавливается `ar`.
- `return_counts` (логическое, необязательный, по умолчанию `False`): вернуть ещё число вхождений каждого значения.
- `axis` (целое или `None`, необязательный, по умолчанию `None`): для таблицы `axis=0` ищет уникальные строки, `axis=1` столбцы.
- `equal_nan` (логическое, только по имени, необязательный, по умолчанию `True`): схлопывать ли все `nan` в один.
- `sorted` (логическое, только по имени, необязательный, по умолчанию `True`): сортировать ли результат; с NumPy 2.3.

Возвращает:

- `ndarray` уникальных значений; с любым из `return_…` кортеж массивов: значения и запрошенные дополнения в порядке параметров.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.unique(np.array(['договор', 'трудовой', 'договор']))` | `['договор' 'трудовой']` | без повторов, по алфавиту |
| `np.unique(np.array(['договор', 'трудовой', 'договор']), return_counts=True)[1]` | `[2 1]` | `return_counts=True`: частоты, второй элемент пары |

- Применение: подсчёт дел по категориям; в pandas это `value_counts`.

### np.count_nonzero(a, axis=None, *, keepdims=False)

Дополнительно: на семинарах не используется.

Число ненулевых элементов; для маски — число `True`, то же, что `mask.sum()`.

Параметры:

- `a` (массив, обязательный): что считать.
- `axis` (целое, кортеж или `None`, необязательный, по умолчанию `None`): ось для таблицы: `axis=0` даёт по одному числу на столбец, `axis=1` на строку; без него по всему массиву.
- `keepdims` (логическое, только по имени, необязательный, по умолчанию `False`): сохранять ли свёрнутую ось длиной 1, чтобы результат подставлялся обратно в таблицу.

Возвращает:

- `np.int64`; с `axis` массив.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.count_nonzero(amounts > 100_000)` | `7` | семь дел дороже 100 000 |

## 10. Пропуски

### np.nan

Константа, параметров нет. Значение «неизвестно», not a number. Дробное: массив целых чисел перед записью `nan` переводится в дробный тип `astype(float)`. Любая арифметика с `nan` даёт `nan`, любое сравнение с ним даёт `False`.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.nan == np.nan` | `False` | пропуск не равен даже самому себе |

### np.isnan(x, /, out=None, *, where=True, casting='same_kind', order='K', dtype=None, subok=True, signature=None)

Маска пропусков: `True` там, где стоит `nan`. Единственный способ найти пропуски.

Параметры:

- `x` (массив или число, обязательный): что проверять; только позиционный; для целого массива все `False`, для строкового `TypeError`.
- `out`, `where`, `casting`, `order`, `dtype`, `subok`, `signature` (необязательные): общие параметры универсальных функций, как у математических функций в разделе 6; в курсе не нужны.

Возвращает:

- `ndarray` логический той же формы.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.isnan(days).sum()` | `2` | число пропусков: два незавершённых дела |

- `days[~np.isnan(days)]` — только известные значения; `~` инвертирует маску.
- Ловушка: `days == np.nan` даёт все `False` и ни одного пропуска не находит.

### np.nanmean(a, axis=None, dtype=None, out=None, keepdims=<no value>, *, where=<no value>), np.nanmedian(…), np.nanstd(…), np.nanpercentile(…), np.nanmax(…), np.nanmin(…), np.nansum(…)

Те же статистики, но пропуски не учитываются ни в числителе, ни в знаменателе. Параметры у каждой функции те же, что у обычной версии без приставки `nan`: у `nanmedian` как у `median`, у `nanstd` как у `std`, включая `ddof`, у `nanpercentile` как у `percentile`, включая `q` и `method`, у `nanmax`, `nanmin` и `nansum` как у `max`, `min` и `sum`.

Параметры `nanmean`:

- `a` (массив, обязательный): значения с пропусками.
- `axis` (целое, кортеж или `None`, необязательный, по умолчанию `None`): ось для таблицы: `axis=0` даёт по одному числу на столбец, `axis=1` на строку; без него по всему массиву; `np.nanmean(t, axis=0)` — по столбцам без пропусков.
- `dtype` (тип данных, необязательный, по умолчанию `None`): тип расчёта; для целых массивов `float64`.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив нужной формы, куда записать результат; служебный, в курсе не нужен.
- `keepdims` (логическое, необязательный): сохранять ли свёрнутую ось длиной 1, чтобы результат подставлялся обратно в таблицу.
- `where` (логический массив, только по имени, необязательный): какие элементы учитывать.

Возвращает:

- число; с `axis` массив; если все значения пропуски, `nan` с предупреждением, а `nansum` даёт 0.

| Пример | Результат | Пояснение |
|---|---|---|
| `days.mean()` | `nan` | два пропуска делают среднее неизвестным |
| `np.nanmean(days)` | `79.8` | среднее десяти известных сроков |
| `np.nansum(days)` | `798.0` | сумма известных сроков |
| `np.nanmedian(days)` | `65.5` | медиана известных: между 60 и 71 |
| `np.nanpercentile(days, 90)` | `153.2` | 90 % известных сроков короче; между 150 и 182 |
| `np.nanmax(days)` | `182.0` | самый долгий известный срок |

- Ловушка: обычные `mean`, `median`, `percentile` при пропусках молча возвращают `nan`, без ошибки.

### np.nanargmax(a, axis=None, out=None, *, keepdims=<no value>), np.nanargmin(…)

Позиция наибольшего и наименьшего известного значения. У `nanargmin` параметры те же.

Параметры:

- `a` (массив, обязательный): значения с пропусками.
- `axis` (целое или `None`, необязательный, по умолчанию `None`): ось для таблицы; без неё позиция в массиве, вытянутом в строку.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив нужной формы, куда записать результат; служебный, в курсе не нужен.
- `keepdims` (логическое, только по имени, необязательный): сохранять ли свёрнутую ось длиной 1, чтобы результат подставлялся обратно в таблицу.

Возвращает:

- `np.int64`: позиция, с нуля; если все значения пропуски, `ValueError`.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.nanargmax(days)` | `7` | позиция самого долгого срока: дело 8 |
| `np.argmax(days)` | `4` | обычный `argmax` указал на первый пропуск |

- Ловушка: при пропусках `argmax` возвращает позицию первого `nan` без ошибки, и ответ выглядит правдоподобно.

### Заполнение пропусков

- Медианой известных значений в копии: `filled = days.copy(); filled[np.isnan(filled)] = np.nanmedian(days)`.
- То же одной строкой через `where`: где пропуск, берётся медиана, иначе исходное значение.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.where(np.isnan(days), np.nanmedian(days), days)[:6]` | `[60. 150. 88. 121. 65.5 19.]` | заполнение медианой через `where` |

- Заполнять пропуски стоит только в копии и только зная, зачем: заполненный массив уже не показывает, где данных не было.

### np.nan_to_num(x, copy=True, nan=0.0, posinf=None, neginf=None)

Дополнительно: на семинарах не используется.

Заменяет пропуски и бесконечности числами.

Параметры:

- `x` (массив или число, обязательный): что заполнять.
- `copy` (логическое, необязательный, по умолчанию `True`): при `True` новый массив, при `False` замена на месте.
- `nan` (число, необязательный, по умолчанию `0.0`): чем заменить `nan`.
- `posinf`, `neginf` (число, необязательные, по умолчанию `None`): чем заменить плюс и минус бесконечность; без них берутся наибольшее и наименьшее число типа.

Возвращает:

- `ndarray` той же формы.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.nan_to_num(days[:5], nan=0)` | `[60. 150. 88. 121. 0.]` | пропуск заменён нулём |

## 11. Поиск и сортировка

### np.where(condition, [x, y, ]/)

Новый массив: там, где условие истинно, берётся `x`, иначе `y`. Так число превращается в категорию.

Параметры:

- `condition` (логический массив, обязательный): где брать `x`.
- `x`, `y` (числа, строки или массивы той же формы, необязательные, только вместе): значение для `True` и значение для `False`; все три аргумента подгоняются друг к другу по правилам арифметики массивов. Все аргументы только позиционные.

Возвращает:

- `ndarray` той же формы, что `condition`; без `x` и `y` кортеж массивов позиций, по одному на ось.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.where(amounts[:4] <= 100_000, 'упрощённое', 'общее')` | `['упрощённое' 'общее' 'общее' 'упрощённое']` | до 100 000 упрощённое, иначе общее |

- Ловушка: порядок аргументов — сначала значение для `True`, потом для `False`.
- Форма с одним аргументом `np.where(условие)` возвращает индексы элементов, где условие истинно, внутри кортежа; для таблицы кортеж из двух массивов, номера строк и столбцов. В курсе вместо неё используются маски.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.where(amounts > 500_000)[0]` | `[2 6 11]` | индексы дел дороже 500 000 |

### np.argmax(a, axis=None, out=None, *, keepdims=<no value>), np.argmin(…)

Позиция наибольшего и наименьшего элемента, не значение. По позиции из массива номеров достаётся номер дела. У `argmin` параметры те же; есть и методы `a.argmax()`, `a.argmin()`.

Параметры:

- `a` (массив, обязательный): значения.
- `axis` (целое или `None`, необязательный, по умолчанию `None`): ось для таблицы; без неё позиция в таблице, вытянутой в строку.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив нужной формы, куда записать результат; служебный, в курсе не нужен.
- `keepdims` (логическое, только по имени, необязательный): сохранять ли свёрнутую ось длиной 1, чтобы результат подставлялся обратно в таблицу.

Возвращает:

- `np.int64`: позиция, с нуля; при нескольких равных максимумах первая; с `axis` массив позиций.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.argmax(amounts)` | `2` | позиция самой дорогой цены, с нуля |
| `numbers[np.argmax(amounts)]` | `3` | номер этого дела |
| `np.argmin(amounts)` | `5` | позиция самой дешёвой: 15 000 |

- Ловушка: при пропусках нужны `nanargmax`, `nanargmin`.

### np.sort(a, axis=-1, kind=None, order=None, *, stable=None, descending=None)

Отсортированная копия по возрастанию; исходный массив не меняется.

Параметры:

- `a` (массив, обязательный): значения.
- `axis` (целое или `None`, необязательный, по умолчанию `-1`): ось сортировки, по умолчанию последняя, то есть внутри каждой строки таблицы; `None` вытягивает массив в строку.
- `kind` (`'quicksort'`, `'mergesort'`, `'heapsort'` или `'stable'`, необязательный, по умолчанию `None`, то есть `'quicksort'`): алгоритм; влияет на скорость и на порядок равных элементов.
- `order` (строка или список строк, необязательный, по умолчанию `None`): для массивов с именованными полями, по каким полям сортировать; в курсе не используется.
- `stable` (логическое, только по имени, необязательный, по умолчанию `None`): при `True` равные элементы сохраняют исходный порядок.
- `descending` (логическое, только по имени, необязательный, по умолчанию `None`): при `True` по убыванию; с NumPy 2.5, в 2.4 нет, поэтому в курсе разворот `[::-1]`.

Возвращает:

- `ndarray`: отсортированная копия. Метод `a.sort()` с теми же параметрами сортирует на месте и возвращает `None`: после `a = a.sort()` массив потерян.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.sort(amounts)[:3]` | `[15000 27000 48000]` | три наименьших |
| `np.sort(amounts)[::-1][:3]` | `[1200000 640000 560000]` | разворот `[::-1]`: три наибольших |

- Ловушка: `nan` попадают в конец; хвост сортировки при пропусках — не самые большие значения.

### np.argsort(a, axis=-1, kind=None, order=None, *, stable=None, descending=None)

Позиции элементов в порядке возрастания. Через них один массив сортируется по другому. Параметры те же, что у `np.sort`, и значат то же.

Возвращает:

- `ndarray` целых: позиции элементов в порядке возрастания; `a[np.argsort(a)]` даёт то же, что `np.sort(a)`.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.argsort(amounts)[:3]` | `[5 10 0]` | индексы трёх самых дешёвых дел |
| `numbers[np.argsort(amounts)[::-1][:3]]` | `[3 7 12]` | номера трёх самых дорогих дел |

- Идиома «по убыванию»: `np.argsort(a)[::-1]`. В pandas та же операция — `sort_values`.

## 12. Случайные числа

### np.random.default_rng(seed=None)

Создаёт генератор случайных чисел; все случайные числа берутся из него методами. Создаётся один раз.

Параметры:

- `seed` (`None`, целое, список целых, `SeedSequence` или `BitGenerator`, необязательный, по умолчанию `None`): зерно; с одним и тем же целым зерном при каждом запуске те же числа; при `None` зерно берётся из операционной системы, и числа каждый раз новые; отрицательные числа не допускаются.

Возвращает:

- `Generator`: генератор, обычно его называют `rng`.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.random.default_rng(3).integers(1, 7, size=5)` | `[5 1 2 2 2]` | зерно 3: при каждом запуске те же числа |

- Ловушка: повторный запуск ячейки с уже созданным генератором продолжает последовательность, а не начинает её заново; чтобы повторить с начала, создайте генератор снова.

### rng.integers(low, high=None, size=None, dtype=np.int64, endpoint=False)

Целые числа от `low` до `high` не включая `high`.

Параметры:

- `low` (целое или массив, обязательный): нижняя граница, входит; если `high` не задан, `low` становится верхней границей, а нижняя равна 0.
- `high` (целое или массив, необязательный, по умолчанию `None`): верхняя граница, не входит; при `endpoint=True` входит.
- `size` (целое или кортеж, необязательный, по умолчанию `None`): число элементов или форма `(строки, столбцы)`; без `size` одно число.
- `dtype` (тип целых, необязательный, по умолчанию `np.int64`): тип результата.
- `endpoint` (логическое, необязательный, по умолчанию `False`): включать ли `high`.

Возвращает:

- `ndarray` целых или одно целое.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.random.default_rng(3).integers(10_000, 1_000_000, size=3)` | `[813389 94792 187646]` | три цены исков от 10 000 до 999 999 |
| `np.random.default_rng(3).integers(1, 6, size=5, endpoint=True)` | `[5 1 2 2 2]` | `endpoint=True`: кубик от 1 до 6 включительно |

- Ловушка: правая граница не включается, как в `range` и `arange`, если не задать `endpoint=True`.

### rng.random(size=None, dtype=np.float64, out=None)

Дробные числа от 0 до 1, не включая 1.

Параметры:

- `size` (целое или кортеж, необязательный, по умолчанию `None`): число элементов или форма `(строки, столбцы)`; без `size` одно число.
- `dtype` (`np.float64` или `np.float32`, необязательный, по умолчанию `np.float64`): точность результата.
- `out` (массив, необязательный, по умолчанию `None`): готовый массив той же формы и типа для результата; служебный.

Возвращает:

- `ndarray` дробных чисел или одно число.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.round(np.random.default_rng(3).random(3), 2)` | `[0.09 0.24 0.8]` | три числа от 0 до 1 |
| `np.random.default_rng(3).random((2, 2)).shape` | `(2, 2)` | `size` кортежем: таблица |

- Применение: доля, вероятность; `rng.random(1000) < 0.05` — маска, отмечающая примерно 5 % элементов. Числа в другом диапазоне проще брать через `uniform`, чем растягивать `random`.

### rng.choice(a, size=None, replace=True, p=None, axis=0, shuffle=True)

Случайный выбор элементов из массива или списка.

Параметры:

- `a` (массив, список или целое `n`, обязательный): откуда выбирать; целое `n` означает выбор из `0, 1, …, n-1`.
- `size` (целое или кортеж, необязательный, по умолчанию `None`): сколько элементов или форма; без `size` один элемент.
- `replace` (логическое, необязательный, по умолчанию `True`): с возвращением, повторы возможны; при `False` каждый элемент не более одного раза, и `size` не больше длины `a`.
- `p` (список или массив чисел, необязательный, по умолчанию `None`): вероятности элементов, той же длины, что `a`, с суммой 1; без `p` все равновероятны.
- `axis` (целое, необязательный, по умолчанию 0): для таблицы, вдоль какой оси выбирать; 0 выбирает строки целиком.
- `shuffle` (логическое, необязательный, по умолчанию `True`): при выборе без возвращения перемешивать ли выбранные элементы; `False` быстрее, но порядок не случаен.

Возвращает:

- `ndarray` выбранных элементов или один элемент.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.random.default_rng(3).choice(numbers, size=3, replace=False)` | `[1 3 9]` | `replace=False`: три дела без повторов |
| `np.random.default_rng(3).choice([1, 0], size=10, p=[0.7, 0.3])` | `[1 1 0 1 1 1 1 1 0 1]` | исходы дел, где иск удовлетворяют в 70 % случаев |

- Ловушка: по умолчанию выбор с возвращением, и одно дело может попасть в выборку дважды; для выборочной проверки нужен `replace=False`.

### rng.permutation(x, axis=0), rng.shuffle(x, axis=0)

Перемешивание: `permutation` возвращает перемешанную копию, `shuffle` перемешивает массив на месте.

Параметры:

- `x` (массив или целое `n`, обязательный): что перемешивать; у `permutation` целое `n` означает перемешать `0, 1, …, n-1`; `shuffle` требует массив и меняет его.
- `axis` (целое, необязательный, по умолчанию 0): для таблицы, вдоль какой оси перемешивать; 0 переставляет строки целиком.

Возвращает:

- `permutation`: новый массив; `shuffle`: `None`.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.random.default_rng(3).permutation(np.arange(1, 6))` | `[5 3 2 4 1]` | те же пять номеров в случайном порядке |
| `np.random.default_rng(3).permutation(4)` | `[3 2 1 0]` | число `n`: позиции 0–3 в случайном порядке |

- Ловушка: `a = rng.shuffle(a)` уничтожает массив, в `a` окажется `None`; пишите просто `rng.shuffle(a)`.
- Одинаково перемешать несколько массивов: `idx = rng.permutation(len(amounts))`, затем `amounts[idx]` и `days[idx]`.
- Жеребьёвка по кругу: `order = rng.permutation(numbers)`, дела судьи с номером `j` из `n` — срез с шагом `order[j - 1::n]`.

### rng.normal(loc=0.0, scale=1.0, size=None), rng.uniform(low=0.0, high=1.0, size=None)

Дополнительно: на семинарах не используются.

Дробные числа из нормального распределения со средним `loc` и стандартным отклонением `scale`, и из равномерного от `low` до `high` не включая `high`.

Параметры:

- `loc` (число или массив, необязательный, по умолчанию `0.0`): среднее нормального распределения.
- `scale` (число или массив, необязательный, по умолчанию `1.0`): стандартное отклонение, не отрицательное.
- `low` (число или массив, необязательный, по умолчанию `0.0`): нижняя граница равномерного распределения, входит.
- `high` (число или массив, необязательный, по умолчанию `1.0`): верхняя граница, не входит.
- `size` (целое или кортеж, необязательный, по умолчанию `None`): число элементов или форма `(строки, столбцы)`; без `size` одно число.

Возвращает:

- `ndarray` дробных чисел или одно число.

| Пример | Результат | Пояснение |
|---|---|---|
| `np.round(np.random.default_rng(3).normal(100, 15, size=3), 1)` | `[130.6 61.7 106.3]` | среднее 100, отклонение 15 |
| `np.round(np.random.default_rng(3).uniform(1, 5, size=3), 2)` | `[1.34 1.95 4.21]` | равномерно от 1 до 5 |

- Применение: модельные данные для семинаров о гипотезах; распределения разбираются на семинарах 11–13.

## 13. Чтение CSV без pandas

### np.loadtxt(fname, dtype=float, comments='#', delimiter=None, converters=None, skiprows=0, usecols=None, unpack=False, ndmin=0, encoding=None, max_rows=None, *, quotechar=None, like=None)

Дополнительно: на семинарах не используется.

Читает числовую таблицу из текстового файла в двумерный массив.

Параметры:

- `fname` (строка, путь, открытый файл или список строк, обязательный): путь к файлу относительно папки, из которой запущен Jupyter; файлы `.gz` и `.bz2` распаковываются сами.
- `dtype` (тип данных, необязательный, по умолчанию `float`): тип элементов результата.
- `comments` (строка, список строк или `None`, необязательный, по умолчанию `'#'`): с какого символа начинается комментарий; остаток строки пропускается.
- `delimiter` (строка, необязательный, по умолчанию `None`): разделитель значений, один символ; по умолчанию пробелы, для CSV запятая.
- `converters` (словарь или функция, необязательный, по умолчанию `None`): функции разбора значений: одна для всех столбцов или словарь «номер столбца: функция».
- `skiprows` (целое, необязательный, по умолчанию 0): сколько первых строк пропустить, обычно одну строку заголовка.
- `usecols` (целое или последовательность целых, необязательный, по умолчанию `None`): номера нужных столбцов, с нуля; `None` читает все.
- `unpack` (логическое, необязательный, по умолчанию `False`): при `True` результат транспонирован, чтобы столбцы разошлись по переменным: `x, y = np.loadtxt(…)`.
- `ndmin` (0, 1 или 2, необязательный, по умолчанию 0): наименьшее число осей результата; иначе оси длины 1 убираются.
- `encoding` (строка, необязательный, по умолчанию `None`): кодировка файла; `None` означает системную.
- `max_rows` (целое, необязательный, по умолчанию `None`): сколько строк с данными прочитать после `skiprows`; пустые строки и комментарии не считаются.
- `quotechar` (символ, только по имени, необязательный, по умолчанию `None`): символ кавычек, внутри которых разделитель не разбивает значение; `None` отключает кавычки.
- `like` (массив другой библиотеки, только по имени, необязательный, по умолчанию `None`): ссылка на объект другой библиотеки, чтобы создать её массив вместо массива NumPy; в курсе не используется.

Возвращает:

- `ndarray`: двумерный массив дробных чисел; для одного столбца одномерный.

- `np.loadtxt('datasets/файл.csv', delimiter=',', skiprows=1, usecols=(1, 2))` — числовые столбцы 2 и 3 без заголовка.
- Ловушка: строковые столбцы `loadtxt` не читает; с семинара 4 таблицы читаются `pandas.read_csv`, и это основной способ в курсе.

## 14. Типичные ошибки и их сообщения

| Сообщение или симптом | Причина | Что делать |
|---|---|---|
| `ValueError: The truth value of an array with more than one element is ambiguous` | `and`, `or`, `not` или `if` с массивом; условие без скобок перед `&` | `&`, `\|`, `~`, каждое условие в скобках; в функциях маски и присваивание по маске вместо `if`; для одного ответа по маске `any()` или `all()` |
| `ValueError: operands could not be broadcast together with shapes (12,) (3,)` | арифметика с массивами разной длины | проверить `shape` обоих массивов |
| `AttributeError: 'numpy.ndarray' object has no attribute 'median'` | медиана вызвана как метод | `np.median(a)` |
| результат `nan` вместо числа | в массиве пропуски | `np.nanmean` и другие функции с приставкой `nan`, либо маска `~np.isnan(a)` |
| пропусков «нет», хотя они есть | поиск через `== np.nan` | `np.isnan(a)` |
| `argmax` указал на дело без срока | пропуски в массиве | `np.nanargmax` |
| 32299 вместо 32300 | `astype(int)` отбрасывает дробную часть, а `32.3 * 1000` даёт `32299.999…` | `np.round` перед `astype(int)` |
| срез «последних k» вернул весь массив | `a[-k:]` при `k = 0` | отдельная проверка `k == 0` |
| исходный массив изменился | запись в срез или в аргумент функции без копии | `copy()` перед изменением |
| в переменной `None` вместо массива | `a = rng.shuffle(a)`: `shuffle` меняет массив на месте и ничего не возвращает | `rng.shuffle(a)` без присваивания |
| массив не изменился после `np.append` | результат не присвоен: `np.append` возвращает новый массив | `a = np.append(a, x)` |
| `np.argmax` по таблице дал число больше числа строк | без `axis` индекс считается по таблице, вытянутой в строку | `argmax(axis=0)` или `argmax(axis=1)` |
| `NameError: name 'np' is not defined` | не выполнена ячейка с `import numpy as np` | выполнить ячейки сверху вниз |

Линейная алгебра (`np.dot`, оператор `@`, модуль `np.linalg`) в курсе не используется; описание в официальной документации в разделе Linear algebra.
