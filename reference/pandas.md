## 1. Что такое pandas

pandas — библиотека Python для работы с таблицами. Её основные типы данных: **DataFrame** — таблица со строками и именованными столбцами, и **Series** — один столбец, набор значений с **индексом**, то есть меткой у каждого значения. Внутри столбца лежит массив NumPy, поэтому всё, что умеет массив, умеет и столбец: арифметика, маски, статистики. Сверх массива таблица даёт то, чего в NumPy приходилось добиваться руками.

- **Имена столбцов и метки строк.** Столбец берётся по имени, строка — по метке, например по номеру дела или ДТП; при отборе строк метки едут вместе с данными, и не нужен отдельный массив номеров.
- **Разные типы в соседних столбцах.** Числа, текст и даты живут в одной таблице; у каждого столбца свой тип.
- **Пропуски.** Значение `NaN` считается пропуском: статистики его пропускают, а не превращают результат в `nan`, как в NumPy.
- **Чтение и запись файлов.** CSV, Excel и другие форматы читаются одной функцией и так же записываются.
- **Группировка и объединение.** Сводные показатели по группам и соединение таблиц по общему столбцу — то, для чего таблицы и нужны.

Цена этих удобств — больше правил: у строки есть и метка, и позиция, и путать их нельзя; таблица не меняется на месте, методы возвращают новую таблицу; результат бывает то Series, то DataFrame в зависимости от того, как задан выбор.

Официальная документация: [pandas.pydata.org/docs](https://pandas.pydata.org/docs/): вводный урок [10 minutes to pandas](https://pandas.pydata.org/docs/user_guide/10min.html), руководство пользователя [User Guide](https://pandas.pydata.org/docs/user_guide/index.html) и справочник по всем функциям [API reference](https://pandas.pydata.org/docs/reference/index.html). Курс работает с pandas 3.0; в старых версиях текстовые столбцы показываются типом `object`, а не `str`. Здесь собраны функции семинаров 4–6 и несколько соседних с ними: у функций семинаров 5 и 6 первой строкой карточки стоит номер семинара, у функций, которых на семинарах нет, — «Дополнительно». В карточке функции: полная подпись в заголовке, что делает, каждый параметр с типом, обязательностью и значением по умолчанию, что возвращает, примеры с пояснением, ловушки и применение там, где они есть. Параметры, названные служебными, нужны для полноты, в курсе они не встречаются. У `read_csv` полный список параметров вынесен из заголовка в карточку: их больше сорока; у статистик таблицы и `Timestamp` в заголовке главные параметры, остальные в карточке.

## 2. Подключение и вывод

### import pandas as pd

Библиотека входит в окружение курса `courses` и подключается один раз в начале ноутбука под коротким именем `pd`; все функции вызываются как `pd.имя`, методы — через точку после таблицы или столбца. Версию показывает `pd.__version__`; в курсе pandas не ниже 3.0.

### Как читать вывод

- Series печатается столбиком: слева метки индекса, справа значения; последняя строка `Name: amount, dtype: int64` — имя столбца и тип. Над метками может стоять имя индекса, например `number`.
- DataFrame печатается таблицей: заголовок со столбцами, ниже строка с именем индекса, затем строки. Длинная таблица обрезается: печатаются первые и последние строки, между ними многоточие; так же обрезаются длинные столбцы.
- Обрезку настраивают `pd.set_option('display.max_rows', 100)` и `pd.set_option('display.max_columns', None)`: по умолчанию печатается не больше 60 строк; `pd.reset_option('display.max_rows')` возвращает настройку.
- `NaN` в ячейке — пропуск; в столбце дат пропуск печатается как `NaT`.
- Тип `str` у текстовых столбцов, `int64` у целых, `float64` у дробных, `datetime64[us]` у дат, `category` у категорий; столбец с пропусками среди целых становится `float64`, поэтому в нём `60.0` вместо `60`.
- Строка таблицы, взятая через `loc`, печатается как Series с `dtype: object`: в ней перемешаны числа и текст.
- Одно число из столбца в ноутбуке печатается с пометкой типа, `np.int64(3)`; `print` напечатает просто `3`. В примерах ниже результаты показаны так, как их печатает `print`.
- Результат группировки по двум столбцам печатается с двухуровневым индексом: повторяющаяся метка первого уровня не печатается заново.

## 4. Series: столбец с метками

### pd.Series(data=None, index=None, dtype=None, name=None, copy=None)

Создаёт столбец: значения с индексом.

Параметры:

- `data` (список, массив, словарь или число, необязательный, по умолчанию `None`): значения; из словаря ключи становятся индексом; число повторяется на всю длину индекса.
- `index` (список меток той же длины, необязательный, по умолчанию `None`): метки; без него нумерация с нуля.
- `dtype` (тип данных, необязательный, по умолчанию `None`): тип значений; если не задан, подбирается по данным.
- `name` (строка, необязательный, по умолчанию `None`): имя столбца; печатается в последней строке вывода и становится именем столбца при добавлении в таблицу.
- `copy` (логическое, необязательный, по умолчанию `None`): копировать ли переданный массив; служебный.

Возвращает:

- `Series`.

| Пример | Результат | Пояснение |
|---|---|---|
| `pd.Series([48_000, 250_000, 1_200_000])` | `0 48000; 1 250000; 2 1200000; dtype: int64` | без `index` метки 0, 1, 2 |
| `pd.Series({'А40': 30, 'А56': 45})` | `А40 30; А56 45; dtype: int64` | из словаря: ключи стали метками |
| `pd.Series([48_000, 250_000], index=[1, 2], name='amount')` | `1 48000; 2 250000; Name: amount, dtype: int64` | метки и имя заданы явно |

- Применение: в курсе Series почти всегда получается как столбец таблицы, `cases['amount']`, а не создаётся вручную.

### s.index, s.values, s.name, s.dtype

Атрибуты столбца, читаются без скобок: метки, значения массивом NumPy, имя, тип элементов. Параметров нет.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['amount'].index[:3]` | `RangeIndex(start=1, stop=4, step=1, name='number')` | метки первых трёх дел, у индекса есть имя |
| `cases['amount'].values[:3]` | `[48000 250000 1200000]` | значения — обычный массив NumPy |
| `cases['amount'].name` | `amount` | имя столбца |
| `cases['amount'].dtype` | `int64` | тип элементов |

### Арифметика и сравнения

Операции `+`, `-`, `*`, `/`, `**` и сравнения работают поэлементно, как у массива: столбец с числом — к каждому значению, два столбца — попарно по совпадающим меткам. Индекс сохраняется, результат — новый Series. Сравнение даёт логический Series, маску, см. раздел 8.

| Пример | Результат | Пояснение |
|---|---|---|
| `(cases['amount'] / 1000).head(3)` | `number; 1 48.0; 2 250.0; 3 1200.0; Name: amount, dtype: float64` | цены в тысячах, метки те же |
| `(cases['amount'] > 500_000).sum()` | `3` | сравнение дало маску, её сумма — число дел |

- Ловушка: два столбца складываются по меткам, а не по позициям; столбцы одной таблицы совпадают по меткам всегда, столбцы разных таблиц — не обязательно, и у несовпавших меток получится `NaN`.

### s.mean(), s.median(), s.sum(), s.min(), s.max(), s.std(ddof=1), s.count()

Статистики столбца; общая подпись `s.mean(axis=0, skipna=True, numeric_only=False, **kwargs)`, у `std` ещё `ddof=1`. Пропуски пропускаются: среднее считается по известным значениям, `count` считает только их.

Параметры:

- `axis` (0, необязательный, по умолчанию 0): у Series единственная ось; нужен для единообразия с таблицей.
- `skipna` (логическое, необязательный, по умолчанию `True`): пропускать ли `NaN`; при `False` любой пропуск даёт `NaN`, как в NumPy.
- `numeric_only` (логическое, необязательный, по умолчанию `False`): у Series не используется; для таблицы см. раздел 15.
- `ddof` (целое, необязательный, по умолчанию 1, только у `std` и `var`): поправка знаменателя; в NumPy по умолчанию 0, поэтому `std` одного и того же столбца в pandas и NumPy различаются.

Возвращает:

- число: `np.float64` или `np.int64`; медиана всегда дробная.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['amount'].mean()` | `314833.3333333333` | средняя цена иска |
| `cases['amount'].median()` | `192500.0` | медиана — метод, у массива NumPy её не было |
| `cases['amount'].sum()` | `3778000` | общая цена исков |
| `cases['days'].mean()` | `79.8` | два пропуска пропущены, среднее по десяти делам |
| `cases['days'].count()` | `10` | известных сроков десять из двенадцати |
| `cases['amount'].std()` | `349476.44824621285` | `ddof=1`: делитель 11 |

- Ловушка: в NumPy `mean` массива с пропуском давал `nan`; здесь пропуски пропускаются молча, и число, по которому считалось среднее, видно только по `count`.

### s.idxmax(axis=0, skipna=True), s.idxmin(axis=0, skipna=True)

Метка наибольшего и наименьшего значения: номер дела, а не позиция.

Параметры:

- `axis` (0, необязательный, по умолчанию 0): единственная ось Series.
- `skipna` (логическое, необязательный, по умолчанию `True`): пропускать ли `NaN`; при `False` пропуск даёт ошибку.

Возвращает:

- метку индекса; при нескольких равных значениях первую.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['amount'].idxmax()` | `3` | номер самого дорогого дела |
| `cases['amount'].idxmin()` | `6` | номер самого дешёвого |
| `cases.loc[cases['amount'].idxmax(), 'court']` | `А56` | по метке достаётся любое поле дела |

- Ловушка: `argmax` из NumPy вернул бы позицию 2; в таблице с номерами дел в индексе позиция и номер расходятся.

### s.loc[метка], s.iloc[позиция]

Элемент по метке индекса и по позиции; со срезом — часть столбца. Подробно о выборе строк таблицы — раздел 7.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['amount'].loc[3]` | `1200000` | дело с номером 3 |
| `cases['amount'].iloc[3]` | `75000` | четвёртое дело по счёту, позиции с нуля |
| `cases['amount'].loc[3:5]` | `number; 3 1200000; 4 75000; 5 320000; Name: amount, dtype: int64` | срез по меткам включает правую границу |
| `cases['amount'].iloc[3:5]` | `number; 4 75000; 5 320000; Name: amount, dtype: int64` | срез по позициям правую границу не включает |

### s.value_counts(normalize=False, sort=True, ascending=False, bins=None, dropna=True)

Сколько раз встречается каждое значение: главный инструмент для текстовых столбцов.

Параметры:

- `normalize` (логическое, необязательный, по умолчанию `False`): при `True` доли вместо чисел.
- `sort` (логическое, необязательный, по умолчанию `True`): сортировать ли по частоте.
- `ascending` (логическое, необязательный, по умолчанию `False`): по умолчанию частые сверху.
- `bins` (целое, необязательный, по умолчанию `None`): для чисел разбить на столько интервалов и считать по интервалам.
- `dropna` (логическое, необязательный, по умолчанию `True`): не считать пропуски; при `False` пропуски отдельной строкой.

Возвращает:

- `Series`: индекс — значения столбца, значения — их частоты или доли; имя `count` или `proportion`.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['category'].value_counts()` | `category; договор 6; неустойка 4; трудовой 2; Name: count, dtype: int64` | по убыванию частоты |
| `cases['category'].value_counts(normalize=True).round(2)` | `category; договор 0.50; неустойка 0.33; трудовой 0.17; Name: proportion, dtype: float64` | доли категорий |
| `cases['outcome'].value_counts(dropna=False)` | `outcome; удовлетворён 8; отказано 2; NaN 2; Name: count, dtype: int64` | пропуски посчитаны отдельно |
| `cases['category'].value_counts().index[0]` | `договор` | самое частое значение |

- Ловушка: без `dropna=False` пропуски не видны, и доли считаются от числа известных значений.

### s.unique(), s.nunique(dropna=True)

Разные значения столбца и их число.

Параметры:

- `dropna` (логическое, необязательный, по умолчанию `True`, только у `nunique`): не считать пропуск за значение.

Возвращает:

- `unique`: массив значений в порядке первого появления; `nunique`: целое.

| Пример | Результат | Пояснение |
|---|---|---|
| `list(cases['category'].unique())` | `['договор', 'неустойка', 'трудовой']` | в порядке появления, не по алфавиту |
| `cases['category'].nunique()` | `3` | число разных категорий |
| `cases['outcome'].nunique(dropna=False)` | `3` | пропуск посчитан как третье значение |

### s.tolist(), s.to_dict(*, into=dict)

Столбец обычным списком или словарём Python.

Параметры:

- `into` (тип словаря, только по имени, необязательный, по умолчанию `dict`): какой словарь построить; служебный.

Возвращает:

- `tolist`: список обычных чисел или строк; `to_dict`: словарь, где ключи — метки, значения — значения столбца.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['amount'].tolist()[:3]` | `[48000, 250000, 1200000]` | числа стали обычными `int` |
| `cases['court'].head(3).to_dict()` | `{1: 'А40', 2: 'А40', 3: 'А56'}` | номера дел — ключи |

- Применение: тесты в упражнениях сравнивают `result.tolist()` со списком; `index.tolist()` даёт список меток.

## 5. DataFrame: устройство и просмотр

### pd.DataFrame(data=None, index=None, columns=None, dtype=None, copy=None)

Создаёт таблицу из словаря столбцов, списка строк или массива.

Параметры:

- `data` (словарь «имя столбца: список», список списков, массив или другая таблица, необязательный, по умолчанию `None`): содержимое; из словаря ключи становятся именами столбцов.
- `index` (список меток, необязательный, по умолчанию `None`): метки строк; без него нумерация с нуля.
- `columns` (список имён, необязательный, по умолчанию `None`): имена столбцов для данных без имён, например для списка списков; для словаря — какие столбцы взять и в каком порядке.
- `dtype` (тип данных, необязательный, по умолчанию `None`): один тип для всех столбцов; обычно не задают.
- `copy` (логическое, необязательный, по умолчанию `None`): копировать ли данные; служебный.

Возвращает:

- `DataFrame`.

### df.set_index(keys, *, drop=True, append=False, inplace=False, verify_integrity=False), df.reset_index(level=None, *, drop=False, inplace=False, col_level=0, col_fill='', allow_duplicates=<no_default>, names=None)

### df.rename(mapper=None, *, index=None, columns=None, axis=None, copy=None, inplace=False, level=None, errors='ignore'), df.drop(labels=None, *, axis=0, index=None, columns=None, level=None, inplace=False, errors='raise')

Семинар 5

Переименовать столбцы или метки; убрать столбцы или строки.

Параметры:

- `columns` (словарь «старое: новое» или функция, необязательный, по умолчанию `None`): у `rename` что переименовать, у `drop` какие столбцы убрать.

- `errors` (`'ignore'` или `'raise'`, необязательный): что делать с именем, которого нет; у `rename` по умолчанию молча пропускается, у `drop` — ошибка `KeyError`.

## 6. Чтение и запись файлов

### pd.read_csv(filepath_or_buffer, *, sep=',', header='infer', names=None, index_col=None, usecols=None, dtype=None, skiprows=None, nrows=None, na_values=None, parse_dates=None, encoding=None, …)

Читает таблицу из текстового файла с разделителями. Полный список параметров ниже; все, кроме пути, задаются только по имени.

Параметры, которые нужны в курсе:

- `filepath_or_buffer` (строка с путём, `Path`, адрес в интернете или открытый файл, обязательный): что читать; путь считается от папки, из которой запущен ноутбук.
- `sep` (строка, необязательный, по умолчанию `','`): разделитель значений; у российских порталов часто `';'`; `delimiter` — то же под другим именем.
- `header` (целое, список или `None`, необязательный, по умолчанию `'infer'`): номер строки с именами столбцов; `None`, если имён в файле нет.
- `names` (список строк, необязательный, по умолчанию `None`): свои имена столбцов.
- `index_col` (имя или номер столбца, необязательный, по умолчанию `None`): какой столбец сделать индексом.
- `usecols` (список имён или номеров, необязательный, по умолчанию `None`): читать только эти столбцы.
- `dtype` (тип или словарь «столбец: тип», необязательный, по умолчанию `None`): типы столбцов вместо угадывания; например `{'id': str}`, чтобы номера с ведущими нулями не стали числами.
- `skiprows` (целое или список, необязательный, по умолчанию `None`): сколько строк пропустить в начале или какие именно.
- `nrows` (целое, необязательный, по умолчанию `None`): прочитать только столько строк; удобно посмотреть на большой файл.
- `na_values` (строка или список, необязательный, по умолчанию `None`): какие значения считать пропусками сверх стандартных: пустая ячейка, `NA`, `NaN`, `null`.
- `parse_dates` (список столбцов, необязательный, по умолчанию `None`): какие столбцы сразу перевести в даты; `date_format` задаёт формат, `dayfirst=True` — день перед месяцем.
- `encoding` (строка, необязательный, по умолчанию `None`, то есть UTF-8): кодировка файла; `'cp1251'` для файлов из Windows-программ, когда русские буквы читаются как мусор.
- `thousands`, `decimal` (строки, необязательные, по умолчанию `None` и `'.'`): разделитель тысяч и десятичный разделитель; `decimal=','` для чисел вида `12,5`.

Остальные параметры, служебные: `engine` (какой разборщик использовать), `converters` (функции разбора столбцов), `true_values`, `false_values` (какие строки считать логическими значениями), `skipinitialspace` (убирать пробелы после разделителя), `skipfooter` (сколько строк пропустить в конце), `keep_default_na`, `na_filter` (управление стандартными пропусками), `skip_blank_lines` (пропускать пустые строки), `yearfirst`, `cache_dates` (разбор дат), `iterator`, `chunksize` (чтение по частям), `compression` (архивы, по умолчанию определяется по расширению), `lineterminator` (символ конца строки), `quotechar`, `quoting`, `doublequote`, `escapechar` (кавычки внутри значений), `comment` (символ комментария), `encoding_errors` (что делать с нечитаемыми байтами), `dialect` (набор настроек CSV), `on_bad_lines` (что делать с испорченными строками), `low_memory`, `memory_map`, `float_precision` (память и точность), `storage_options` (доступ к облачным хранилищам), `dtype_backend` (какие типы использовать для пропусков).

Возвращает:

- `DataFrame`.

Три столбца и три строки из файла кейса: номер ДТП остался столбцом, строки пронумерованы с нуля:

```python
>>> pd.read_csv('../datasets/legal/dtp-bryansk.csv', usecols=['id', 'category', 'dead_count'], nrows=3)
    id              category  dead_count
0   31  Наезд на препятствие           0
1  133          Столкновение           0
2  177          Столкновение           1
```

| Пример | Результат | Пояснение |
|---|---|---|
| `pd.read_csv('../datasets/legal/dtp-bryansk.csv', index_col='id').shape` | `(10114, 14)` | номер ДТП стал индексом и в столбцы не входит |
| `pd.read_csv('../datasets/legal/dtp-bryansk.csv', index_col='id', nrows=2).index.tolist()` | `[31, 133]` | метки первых двух ДТП |

- Ловушка: неверный путь даёт `FileNotFoundError`; файл с `;` при `sep=','` читается как один столбец с длинными строками; файл в cp1251 без `encoding` даёт `UnicodeDecodeError`.

### df.to_csv(path_or_buf=None, *, sep=',', na_rep='', float_format=None, columns=None, header=True, index=True, index_label=None, mode='w', encoding=None, compression='infer', quoting=None, quotechar='"', lineterminator=None, chunksize=None, date_format=None, doublequote=True, escapechar=None, decimal='.', errors='strict', storage_options=None)

Записывает таблицу в текстовый файл с разделителями.

Параметры:

- `path_or_buf` (строка с путём или открытый файл, необязательный, по умолчанию `None`): куда писать; без него текст возвращается строкой.
- `sep` (строка, необязательный, по умолчанию `','`): разделитель.
- `na_rep` (строка, необязательный, по умолчанию `''`): как записать пропуск; по умолчанию пустая ячейка.
- `float_format` (строка формата, необязательный, по умолчанию `None`): например `'%.2f'` для двух знаков после запятой.
- `columns` (список имён, необязательный, по умолчанию `None`): записать только эти столбцы.
- `header` (логическое или список, необязательный, по умолчанию `True`): писать ли строку с именами столбцов, или свои имена.
- `index` (логическое, необязательный, по умолчанию `True`): писать ли индекс первым столбцом; для нумерации с нуля обычно `False`.
- `index_label` (строка, необязательный, по умолчанию `None`): имя для столбца индекса.
- `mode` (строка, необязательный, по умолчанию `'w'`): `'a'` дописывает в конец файла.
- `encoding` (строка, необязательный, по умолчанию `None`, то есть UTF-8): кодировка файла.
- `decimal` (строка, необязательный, по умолчанию `'.'`): десятичный разделитель, `','` для Excel в русских настройках.
- `date_format` (строка формата, необязательный, по умолчанию `None`): как записать даты.
- Служебные: `compression`, `quoting`, `quotechar`, `lineterminator`, `chunksize`, `doublequote`, `escapechar`, `errors`, `storage_options`: архивирование, кавычки, конец строки, запись по частям, обработка ошибок кодировки, облачные хранилища.

Возвращает:

- `None`, если задан путь; иначе строку с содержимым файла.

Без пути строка, которую получил бы файл: индекс первым столбцом, пропуск пустой ячейкой:

```python
>>> print(cases.head(2).to_csv())
number,amount,days,outcome,category,court,filed
1,48000,60.0,удовлетворён,договор,А40,2026-02-02
2,250000,150.0,отказано,договор,А40,2026-02-03
```

- Применение: `cases.to_csv('cases.csv', index=False)` записывает файл рядом с ноутбуком без столбца индекса; выборка для отчёта на семинаре 4 записана с индексом, чтобы сохранить номера ДТП.

## 7. Выбор столбцов и строк

### df['col'], df[['a', 'b']]

Один столбец по имени — Series; список имён во вторых квадратных скобках — таблица из этих столбцов.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['court'].head(3)` | `number; 1 А40; 2 А40; 3 А56; Name: court, dtype: str` | столбец — Series с индексом таблицы |
| `cases[['amount', 'days']].shape` | `(12, 2)` | два столбца — таблица |
| `cases[['amount']].shape` | `(12, 1)` | список из одного имени тоже таблица |

- Ловушка: `cases['amount', 'days']` без внутренних скобок ищет один столбец с составным именем и даёт `KeyError`.
- Точечная запись `cases.amount` работает для простых имён, но не для имён с пробелами и не для новых столбцов; в курсе только квадратные скобки.

### df.loc[метки, столбцы]

Выбор по меткам: одна метка даёт строку как Series, список меток — таблицу, срез меток включает обе границы; вторым аргументом столбец или список столбцов. Тот же `loc` с маской вместо меток — раздел 8.

Одна метка даёт строку как Series: индексом стали имена столбцов, тип `object`, потому что в строке перемешаны числа и текст:

```python
>>> cases.loc[3]
amount           1200000
days                88.0
outcome     удовлетворён
category       неустойка
court                А56
filed         2026-02-05
Name: 3, dtype: object
```

| Пример | Результат | Пояснение |
|---|---|---|
| `cases.loc[3, 'amount']` | `1200000` | одно поле |
| `cases.loc[[3, 7], 'court'].tolist()` | `['А56', 'А56']` | два дела, одно поле |
| `cases.loc[3:5, 'amount'].tolist()` | `[1200000, 75000, 320000]` | срез меток включает 5 |

Несколько дел и несколько полей списками:

```python
>>> cases.loc[[3, 7], ['amount', 'court']]
         amount court
number
3       1200000   А56
7        640000   А56
```

- Ловушка: метки, которой нет, `cases.loc[13]` даёт `KeyError: 13`.
- Присваивание: `cases.loc[3, 'days'] = 90` меняет одно поле; `cases.loc[маска, 'col'] = значение` меняет поле у отобранных строк.

### df.iloc[позиции, позиции столбцов]

Выбор по позициям, с нуля; правая граница среза не входит, как у массива.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases.iloc[2]['court']` | `А56` | третья строка по счёту, это дело 3 |
| `cases.iloc[0, 0]` | `48000` | первая строка, первый столбец |
| `cases.iloc[:2].index.tolist()` | `[1, 2]` | первые две строки |
| `cases.iloc[-1]['court']` | `А56` | последняя строка |
| `cases.iloc[3:5]['amount'].tolist()` | `[75000, 320000]` | позиции 3 и 4 |

- Ловушка: позиция за пределами таблицы, `cases.iloc[12]` для двенадцати строк, даёт `IndexError`; `cases.iloc[1236155]` с номером ДТП вместо позиции падает так же.
- Срез `cases.iloc[-k:]` при `k = 0` возвращает всю таблицу, потому что `-0` это `0`; та же ловушка, что у массива.

## 8. Маски и фильтрация

### Маска

Сравнение столбца с числом или строкой даёт логический Series с тем же индексом. Маска в квадратных скобках таблицы оставляет строки с `True`; сумма маски — их число, среднее — доля. Условия соединяются `&`, `|`, `~`, каждое в скобках.

| Пример | Результат | Пояснение |
|---|---|---|
| `(cases['amount'] > 500_000).sum()` | `3` | дел дороже 500 000 |
| `(cases['court'] == 'А56').mean().round(2)` | `0.42` | доля дел в суде А56 |
| `cases[(cases['court'] == 'А40') & (cases['amount'] > 100_000)].index.tolist()` | `[2, 9]` | два условия через `&` |
| `cases[~(cases['category'] == 'договор')].shape` | `(6, 6)` | отрицание через `~` |

Строки по условию и нужные столбцы через `loc`:

```python
>>> cases.loc[cases['days'] > 100, ['days', 'court']]
         days court
number
2       150.0   А40
4       121.0   А40
8       182.0   А40
```

- Ловушка: `and`, `or`, `not` вместо `&`, `|`, `~` и условие без скобок дают `ValueError: The truth value of a Series is ambiguous`.
- Сравнение с пропуском всегда `False`: строки с `NaN` в `days` не попадают ни в `days > 100`, ни в `days <= 100`.

### s.isin(values)

Маска значений, которые входят в список.

Параметры:

- `values` (список, множество или Series, обязательный): допустимые значения.

Возвращает:

- логический Series той же длины.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['category'].isin(['неустойка', 'трудовой']).sum()` | `6` | дел двух категорий |
| `cases[cases['court'].isin(['А56'])].shape` | `(5, 6)` | то же, что `== 'А56'`, но список можно удлинять |

- Применение: три ночных значения освещения в кейсе ДТП одним `isin` вместо цепочки `|`.

### s.between(left, right, inclusive='both')

Маска значений в диапазоне.

Параметры:

- `left`, `right` (числа, строки или даты, обязательные): границы.
- `inclusive` (`'both'`, `'neither'`, `'left'` или `'right'`, необязательный, по умолчанию `'both'`): какие границы входят.

Возвращает:

- логический Series.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['amount'].between(50_000, 150_000).sum()` | `3` | цены 75 000, 98 000 и 135 000 |
| `cases['amount'].between(48_000, 75_000, inclusive='neither').sum()` | `0` | границы исключены, между ними ничего нет |

### df.query(expr, *, parser='pandas', engine=None, local_dict=None, global_dict=None, resolvers=None, level=0, inplace=False)

Семинар 5

Отбор строк условием, записанным строкой: имена столбцов без кавычек, `and` и `or` вместо `&` и `|`.

Параметры:

- `expr` (строка, обязательный): условие; значение из переменной подставляется через `@имя`.
- `parser`, `engine` (строки, необязательные): как разбирать и вычислять выражение; служебные.
- `local_dict`, `global_dict`, `resolvers`, `level` (служебные): откуда брать переменные.
- `inplace` (логическое, необязательный, по умолчанию `False`): менять таблицу на месте; в курсе не используется.

Возвращает:

- новую таблицу.

Условие строкой; результат тот же, что у маски:

```python
>>> cases.query('days > 100')
        amount   days       outcome  category court       filed
number
2       250000  150.0      отказано   договор   А40  2026-02-03
4        75000  121.0  удовлетворён  трудовой   А40  2026-02-09
8        98000  182.0      отказано   договор   А40  2026-02-17
```

| Пример | Результат | Пояснение |
|---|---|---|
| `cases.query('court == "А56" and amount > 500_000').index.tolist()` | `[3, 7, 12]` | строка в условии в двойных кавычках |
| `limit = 100; cases.query('days > @limit').shape` | `(3, 6)` | переменная через `@` |

- Ловушка: имя столбца с пробелом или дефисом берётся в обратные кавычки: `` `dead count` > 0 ``.

### s.str.contains(pat, case=True, flags=0, na=<no_default>, regex=True), s.str.startswith(pat, na=<no_default>)

Семинар 5

Маски по тексту: содержит ли строка подстроку, начинается ли с неё. Методы текста живут под `s.str`.

Параметры:

- `pat` (строка, обязательный): подстрока или регулярное выражение; у `startswith` также кортеж строк.
- `case` (логическое, необязательный, по умолчанию `True`, у `contains`): различать ли регистр.
- `flags` (целое, необязательный, по умолчанию 0, у `contains`): флаги регулярных выражений; служебный.
- `na` (значение, необязательный, у обоих): что считать результатом у пропуска; по умолчанию пропуск даёт `False`.
- `regex` (логическое, необязательный, по умолчанию `True`, у `contains`): считать ли `pat` регулярным выражением; для точки, скобок и знака вопроса в обычном тексте нужен `regex=False`.

Возвращает:

- логический Series; у пропусков `False`, если `na` не задан.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['category'].str.contains('дог').sum()` | `6` | категории со словом «договор» |
| `cases['category'].str.startswith('не').sum()` | `4` | категории, начинающиеся с «не» |
| `cases['category'].str.contains('ДОГ', case=False).sum()` | `6` | без учёта регистра |
| `cases['outcome'].str.contains('удов').sum()` | `8` | два пропуска в исходах посчитаны как `False` |
| `cases['outcome'].str.contains('удов', na=True).sum()` | `10` | `na=True`: пропуск считается совпадением |

- Ловушка: буквы е и ё для `contains` разные: «темное» в кейсе ДТП записано без ё, и поиск по «тёмное» ничего не найдёт.

### s.str.lower(), s.str.upper(), s.str.len(), s.str.strip(to_strip=None), s.str.replace(pat, repl=None, n=-1, case=None, flags=0, regex=False)

Дополнительно: на семинарах не используется.

Преобразования текста поэлементно: регистр, длина, обрезка пробелов, замена подстроки.

Параметры:

- `to_strip` (строка, необязательный, по умолчанию `None`, у `strip`): какие символы убирать с краёв; по умолчанию пробелы.
- `pat`, `repl` (строки, обязательные, у `replace`): что и на что заменить.
- `n` (целое, необязательный, по умолчанию -1, у `replace`): сколько замен в одной строке; -1 означает все.
- `case`, `flags`, `regex` (необязательные, у `replace`): регистр, флаги и режим регулярных выражений; по умолчанию обычный текст.

Возвращает:

- Series строк; у `len` — чисел.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['court'].str.lower().head(2).tolist()` | `['а40', 'а40']` | буквы в нижнем регистре |
| `cases['category'].str.len().head(3).tolist()` | `[7, 7, 9]` | длина каждой строки |
| `cases['court'].str.replace('А', 'A').head(2).tolist()` | `['A40', 'A40']` | русская «А» заменена на латинскую |
| `pd.Series([' А40 ']).str.strip().tolist()` | `['А40']` | пробелы по краям убраны |

- Применение: чистка категорий перед `value_counts`: один и тот же суд, записанный с пробелом или в другом регистре, считается разными значениями.

## 9. Сортировка

### df.sort_values(by, *, axis=0, ascending=True, inplace=False, kind='quicksort', na_position='last', ignore_index=False, key=None)

Семинар 5

Строки таблицы в порядке значений одного или нескольких столбцов; у Series тот же метод без `by`.

Параметры:

- `by` (имя столбца или список имён, обязательный): по чему сортировать; при списке следующий столбец решает при равенстве.
- `axis` (0 или 1, необязательный, по умолчанию 0): сортировать строки или столбцы; служебный.
- `ascending` (логическое или список логических, необязательный, по умолчанию `True`): по возрастанию; список задаёт направление для каждого столбца из `by`.
- `inplace` (логическое, необязательный, по умолчанию `False`): менять на месте; в курсе не используется.
- `kind` (строка, необязательный, по умолчанию `'quicksort'`): алгоритм; `'stable'` сохраняет порядок равных.
- `na_position` (`'last'` или `'first'`, необязательный, по умолчанию `'last'`): куда ставить пропуски.
- `ignore_index` (логическое, необязательный, по умолчанию `False`): заменить ли метки нумерацией с нуля.
- `key` (функция, необязательный, по умолчанию `None`): преобразование значений перед сравнением, например `str.lower`.

Возвращает:

- новую таблицу; исходная не меняется.

Три самых дешёвых дела; индекс сохранил номера:

```python
>>> cases.sort_values('amount').head(3)
        amount  days       outcome   category court       filed
number
6        15000  19.0  удовлетворён  неустойка   А40  2026-02-12
11       27000  28.0  удовлетворён   трудовой   А40  2026-02-25
1        48000  60.0  удовлетворён    договор   А40  2026-02-02
```

По суду по возрастанию, внутри суда по убыванию цены:

```python
>>> cases.sort_values(['court', 'amount'], ascending=[True, False]).head(3)
        amount   days       outcome category court       filed
number
9       410000   34.0  удовлетворён  договор   А40  2026-02-19
2       250000  150.0      отказано  договор   А40  2026-02-03
8        98000  182.0      отказано  договор   А40  2026-02-17
```

| Пример | Результат | Пояснение |
|---|---|---|
| `cases.sort_values('amount', ascending=False).index[:3].tolist()` | `[3, 7, 12]` | номера трёх самых дорогих дел |
| `cases['days'].sort_values().tail(3).index.tolist()` | `[8, 5, 10]` | пропуски в конце при любом направлении |
| `cases.sort_values('days', na_position='first').index[:2].tolist()` | `[5, 10]` | пропуски впереди |

- Ловушка: `sort_values` не меняет таблицу; `cases.sort_values('amount')` без присваивания ничего не сохраняет. Пропуски идут в конец и при `ascending=False`.

### df.sort_index(*, axis=0, level=None, ascending=True, inplace=False, kind='quicksort', na_position='last', sort_remaining=True, ignore_index=False, key=None)

Семинар 5

Строки в порядке меток индекса; параметры как у `sort_values`, `level` и `sort_remaining` — для многоуровневого индекса.

Параметры:

- `columns` (имя столбца или список, обязательный): по чему выбирать.
- `keep` (`'first'`, `'last'` или `'all'`, необязательный, по умолчанию `'first'`): что делать с равными значениями на границе.

Возвращает:

- новую таблицу; у Series те же методы без `columns`.

### s.rank(axis=0, method='average', numeric_only=False, na_option='keep', ascending=True, pct=False)

Дополнительно: на семинарах не используется.

Место каждого значения среди остальных.

Параметры:

- `method` (`'average'`, `'min'`, `'max'`, `'first'` или `'dense'`, необязательный, по умолчанию `'average'`): как делить места между равными значениями.
- `na_option` (`'keep'`, `'top'` или `'bottom'`, необязательный, по умолчанию `'keep'`): пропуски остаются пропусками или получают первые или последние места.

## 11. Группировка и сводные таблицы

### df.groupby(by=None, level=None, *, as_index=True, sort=True, group_keys=True, observed=True, dropna=True)

Семинар 5

Разбить строки на группы по значениям столбца и посчитать статистику по каждой группе: `cases.groupby('court')['amount'].mean()` — средняя цена иска в каждом суде.

Параметры:

- `by` (имя столбца, список имён, Series или функция, обязательный): по чему группировать; список даёт группы по сочетаниям значений.
- `level` (уровень индекса, необязательный, по умолчанию `None`): группировать по индексу вместо столбца.
- `as_index` (логическое, необязательный, по умолчанию `True`): ключи групп становятся индексом результата; при `False` остаются столбцом, как после `reset_index()`.
- `sort` (логическое, необязательный, по умолчанию `True`): группы по алфавиту ключей.
- `group_keys` (логическое, необязательный, по умолчанию `True`): добавлять ли ключи в индекс при `apply`; служебный.
- `observed` (логическое, необязательный, по умолчанию `True`): для категориальных столбцов показывать только встретившиеся группы.
- `dropna` (логическое, необязательный, по умолчанию `True`): строки с пропуском в ключе не попадают ни в одну группу.

Возвращает:

- объект группировки; статистика получается его методами: `mean`, `median`, `sum`, `min`, `max`, `count`, `size`, `nunique`, `agg`.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases.groupby('court')['amount'].median()` | `court; А40 75000.0; А56 560000.0; Name: amount, dtype: float64` | медиана цены по судам |
| `cases.groupby('court').size()` | `court; А40 7; А56 5; dtype: int64` | число дел в группе |
| `cases.groupby('court')['days'].mean().round(1)` | `court; А40 84.9; А56 68.0; Name: days, dtype: float64` | пропуски в сроках пропущены |
| `cases.groupby('court')['days'].count()` | `court; А40 7; А56 3; Name: days, dtype: int64` | `count` считает известные значения, `size` — все строки |
| `cases.groupby('court')['category'].nunique()` | `court; А40 3; А56 2; Name: category, dtype: int64` | разных категорий в суде |

Группы по двум столбцам: двухуровневый индекс, метка суда не повторяется:

```python
>>> cases.groupby(['court', 'category']).size()
court  category
А40    договор      4
       неустойка    1
       трудовой     2
А56    договор      2
       неустойка    3
dtype: int64
```

Ключ группы остаётся столбцом при `as_index=False`:

```python
>>> cases.groupby('court', as_index=False)['amount'].sum()
  court   amount
0   А40   923000
1   А56  2855000
```

- Ловушка: `cases.groupby('court').mean()` по всей таблице падает на текстовых столбцах с `TypeError`; нужен `numeric_only=True` или выбор столбца перед статистикой.

### pd.to_datetime(arg, errors='raise', dayfirst=False, yearfirst=False, utc=False, format=None, exact=<no_default>, unit=None, origin='unix', cache=True)

Семинар 6

Перевод строк в даты; после него столбец умеет извлекать год, месяц, день недели и участвовать в арифметике.

Параметры:

- `arg` (строка, Series, список или число, обязательный): что переводить; формат `ГГГГ-ММ-ДД` распознаётся сам.
- `errors` (`'raise'` или `'coerce'`, необязательный, по умолчанию `'raise'`): падать на нечитаемой дате или ставить `NaT`.
- `dayfirst` (логическое, необязательный, по умолчанию `False`): в записи `16.09.2026` день идёт первым; без него `09.10.2026` прочитается как 10 сентября.
- `yearfirst` (логическое, необязательный, по умолчанию `False`): год идёт первым в двусмысленной записи.
- `utc` (логическое, необязательный, по умолчанию `False`): привести к всемирному времени; служебный.
- `format` (строка, необязательный, по умолчанию `None`): формат явно, например `'%d.%m.%Y'`; быстрее и надёжнее угадывания.
- `exact` (логическое, необязательный): требовать ли точного совпадения с форматом.
- `unit` (строка, необязательный, по умолчанию `None`): единица для чисел, например `'s'` для секунд с 1970 года.
- `origin` (необязательный, по умолчанию `'unix'`): точка отсчёта для чисел.
- `cache` (логическое, необязательный, по умолчанию `True`): ускорение при повторяющихся значениях; служебный.

Возвращает:

- Series типа `datetime64` для Series; `Timestamp` для одной строки; `DatetimeIndex` для списка.

| Пример | Результат | Пояснение |
|---|---|---|
| `pd.to_datetime(cases['filed']).dtype` | `datetime64[us]` | столбец стал датами |
| `pd.to_datetime('16.09.2026', dayfirst=True)` | `2026-09-16 00:00:00` | день перед месяцем |
| `pd.to_datetime('2026-09-16 14:30').hour` | `14` | у одной даты поля берутся напрямую |
| `pd.to_datetime(['2026-09-16', 'нет даты'], errors='coerce')[1]` | `NaT` | нечитаемая дата стала пропуском |

- Ловушка: без `dayfirst=True` дата `05.03.2026` прочитается как 3 мая; в столбце ДТП дата и время записаны в одном поле, `to_datetime` читает их вместе.

## 14. Объединение таблиц

### pd.merge(left, right, how='inner', on=None, left_on=None, right_on=None, left_index=False, right_index=False, sort=False, suffixes=('_x', '_y'), copy=<no_default>, indicator=False, validate=None)

Семинар 6

Соединить две таблицы по общему столбцу, как справочник судов с картотекой по коду суда.

Параметры:

- `left`, `right` (таблицы, обязательные): что соединять.
- `how` (`'inner'`, `'left'`, `'right'`, `'outer'` или `'cross'`, необязательный, по умолчанию `'inner'`): какие строки оставить: только совпавшие в обеих таблицах, все из левой, все из правой, все из обеих, все сочетания.
- `on` (имя столбца или список, необязательный, по умолчанию `None`): общий столбец; без него берутся все одноимённые столбцы.
- `left_on`, `right_on` (имена, необязательные): столбцы для соединения, если названы по-разному, как `id` и `dtp_id` в кейсе.
- `left_index`, `right_index` (логические, необязательные, по умолчанию `False`): соединять по индексу вместо столбца.
- `sort` (логическое, необязательный, по умолчанию `False`): сортировать ли результат по ключу.
- `suffixes` (пара строк, необязательный, по умолчанию `('_x', '_y')`): что дописать к одноимённым столбцам, которые не ключи.
- `copy` (служебный).
- `indicator` (логическое, необязательный, по умолчанию `False`): добавить столбец `_merge` с пометкой, из какой таблицы пришла строка.
- `validate` (строка вроде `'one_to_many'`, необязательный, по умолчанию `None`): проверить вид связи и упасть, если ключи повторяются там, где не должны.

Возвращает:

- новую таблицу; индексы исходных таблиц теряются, строки нумеруются с нуля.

Город суда приписан к каждому делу; номер дела ушёл из индекса:

```python
>>> pd.merge(cases, courts, on='court').head(2)
   amount   days       outcome category court       filed    city
0   48000   60.0  удовлетворён  договор   А40  2026-02-02  Москва
1  250000  150.0      отказано  договор   А40  2026-02-03  Москва
```

| Пример | Результат | Пояснение |
|---|---|---|
| `pd.merge(cases, courts, on='court').shape` | `(12, 7)` | все 12 дел нашли свой суд |
| `pd.merge(courts, cases, on='court', how='left').shape` | `(13, 7)` | суд А41 без дел дал строку с пропусками |
| `pd.merge(courts, cases, on='court', how='left')['amount'].isna().sum()` | `1` | эта строка |
| `pd.merge(cases, courts, on='court', how='outer').shape` | `(13, 7)` | все строки обеих таблиц |

- Ловушка: если ключ повторяется в обеих таблицах, строки перемножаются, и таблица растёт; `validate='one_to_many'` ловит это. Чтобы сохранить номера дел, перед `merge` верните их в столбец через `reset_index()`.
- Применение: таблица участников ДТП присоединяется к таблице ДТП: `pd.merge(dtp.reset_index(), participants, left_on='id', right_on='dtp_id')`.

## 15. Статистики

### df.sum(*, axis=0, skipna=True, numeric_only=False, min_count=0, **kwargs), df.mean(…), df.median(…), df.min(…), df.max(…), df.std(…, ddof=1)

Статистики по всей таблице: по одному числу на столбец.

Параметры:

- `axis` (0 или 1, необязательный, по умолчанию 0): 0 — по каждому столбцу, 1 — по каждой строке.

| `cases[['amount', 'days']].max()` | `amount 1200000.0; days 182.0; dtype: float64` | максимумы; тип общий дробный |
| `cases.mean(numeric_only=True).round(1)` | `amount 314833.3; days 79.8; dtype: float64` | текстовые столбцы пропущены |
| `cases[['amount', 'days']].sum()` | `amount 3778000.0; days 798.0; dtype: float64` | суммы; у сроков без пропусков |

- Ловушка: `cases.mean()` по всей таблице падает на текстовых столбцах; нужен `numeric_only=True` или выбор столбцов.

### df.quantile(q=0.5, axis=0, numeric_only=False, interpolation='linear', method='single')

Дополнительно: на семинарах не используется.

Квантили столбца или таблицы: доля от 0 до 1, а не процент.

Параметры:

- `q` (число или список от 0 до 1, необязательный, по умолчанию 0.5): какие квантили.
- `axis` (0 или 1, необязательный, по умолчанию 0): по столбцам или по строкам.
- `numeric_only` (логическое, необязательный, по умолчанию `False`): только числовые столбцы.
- `interpolation` (`'linear'`, `'lower'`, `'higher'`, `'midpoint'` или `'nearest'`, необязательный, по умолчанию `'linear'`): как считать между соседними значениями; как `method` у `np.percentile`.
- `method` (`'single'` или `'table'`, необязательный): служебный.

Возвращает:

- число для одного `q`, Series для списка.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['amount'].quantile(0.9)` | `632000.0` | 90 % дел дешевле |
| `cases['amount'].quantile([0.25, 0.5, 0.75]).tolist()` | `[68250.0, 192500.0, 447500.0]` | квартили |

### df.corr(method='pearson', min_periods=1, numeric_only=False)

Дополнительно: на семинарах не используется, понадобится на семинарах 9–10.

Корреляция между числовыми столбцами.

Параметры:

- `method` (`'pearson'`, `'spearman'` или `'kendall'`, необязательный, по умолчанию `'pearson'`): вид коэффициента.
- `min_periods` (целое, необязательный, по умолчанию 1): сколько пар значений нужно для расчёта.
- `numeric_only` (логическое, необязательный, по умолчанию `False`): только числовые столбцы.

Возвращает:

- таблицу коэффициентов; у Series `s.corr(other)` даёт число.

| Пример | Результат | Пояснение |
|---|---|---|
| `round(cases['amount'].corr(cases['days']), 2)` | `-0.05` | цена и срок в картотеке почти не связаны |

### s.round(decimals=0), s.cumsum(axis=0, skipna=True)

Округление столбца; нарастающий итог.

Параметры:

- `decimals` (целое, необязательный, по умолчанию 0, у `round`): знаков после запятой; отрицательное округляет до десятков и сотен.
- `axis`, `skipna` (необязательные, у `cumsum`): ось и пропуск `NaN`.

Возвращает:

- новый Series; `round` есть и у таблицы, и у чисел из статистик.

| Пример | Результат | Пояснение |
|---|---|---|
| `cases['amount'].round(-3).head(2).tolist()` | `[48000, 250000]` | до тысяч |
| `cases['days'].mean().round(1)` | `79.8` | число из статистики тоже округляется |
| `cases['amount'].cumsum().head(3).tolist()` | `[48000, 298000, 1498000]` | сумма нарастающим итогом |

| `KeyError: 13` или `KeyError: 'amont'` | метки или столбца с таким именем нет | проверить `index`, `columns`; опечатка в имени |

| `ValueError: The truth value of a Series is ambiguous` | `and`, `or`, `not` с масками или условие без скобок | `&`, `\|`, `~`, каждое условие в скобках |
| `TypeError: Cannot perform reduction 'mean' with string dtype`; после `groupby` — `TypeError: dtype 'str' does not support operation 'mean'` | статистика по текстовому столбцу, по всей таблице или по всем столбцам группы | `value_counts` для текста; `numeric_only=True` или выбор числового столбца перед статистикой |

| `AttributeError: 'Series' object has no attribute 'columns'` | метод или атрибут таблицы вызван у столбца, или наоборот | проверить тип: `type(x)`; один столбец — Series, список столбцов — таблица |
