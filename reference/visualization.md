## 1. Что такое matplotlib и seaborn

**matplotlib** — библиотека Python для построения графиков. Её основные объекты: **Figure**, фигура — лист, на котором рисуют, и **Axes**, оси — область с координатами на этом листе; на одной фигуре может быть несколько осей. Всё, что нарисовано, живёт на осях: линии, столбцы, точки, подписи. Методы осей начинаются с `set_`: `set_title`, `set_xlabel`; методы фигуры сохраняют и раскладывают панели: `savefig`, `suptitle`, `tight_layout`. Через matplotlib рисуют и метод `.plot` таблиц pandas, и функции seaborn, поэтому подписи и сохранение у всех трёх устроены одинаково.

**seaborn** — библиотека поверх matplotlib для статистических графиков. Ей передают таблицу и имена столбцов, а сводку она считает сама: `countplot` считает строки по категориям, `barplot` — средние, `histplot` раскладывает значения по бинам, `boxplot` считает квартили. Функции seaborn принимают параметр `ax` и рисуют на переданных осях, возвращая их; так же устроены функции упражнений курса.

Три способа нарисовать одно и то же в курсе:

- **сводка pandas → `.plot`**: когда сводка уже посчитана через `value_counts`, `groupby` или `crosstab`; самый короткий путь;
- **сырая таблица → seaborn**: когда сводку считать не нужно, а нужны распределения и группы;
- **matplotlib напрямую**: устройство рисунка, подписи, панели, сохранение и графики, которых у первых двух нет, например рассеяние по координатам через `ax.scatter`.

Цена: у одного графика три способа, и их легко перемешать; сводка для линии должна идти в порядке периодов; функции seaborn подписывают оси по-английски, подписи заменяются вручную; сохранять надо фигуру по имени, а не «текущую».

Официальная документация: [matplotlib.org/stable](https://matplotlib.org/stable/): быстрый старт [Quick start guide](https://matplotlib.org/stable/users/explain/quick_start.html) и справочник методов осей [Axes](https://matplotlib.org/stable/api/axes_api.html); [seaborn.pydata.org](https://seaborn.pydata.org/): введение [An introduction to seaborn](https://seaborn.pydata.org/tutorial/introduction.html) и справочник функций [API reference](https://seaborn.pydata.org/api.html); графики pandas: [Chart visualization](https://pandas.pydata.org/docs/user_guide/visualization.html). Интерактивные графики и карты строит **plotly**, точнее его модуль `plotly.express` под именем `px`: функции принимают таблицу и имена столбцов, а возвращают фигуру-объект, которая в Jupyter отвечает на наведение и масштаб; документация [plotly.com/python](https://plotly.com/python/), справочник функций [plotly.express](https://plotly.com/python-api-reference/plotly.express.html). Курс работает с matplotlib 3.11, seaborn 0.13 и plotly 6.9; подписи функций ниже взяты из этих версий.

### import matplotlib.pyplot as plt; import seaborn as sns

### Как читать вывод

- Ячейка, последняя строка которой рисует, печатает под графиком возвращаемое значение, например `<Axes: xlabel='datetime'>` или `<Axes: >`; точка с запятой в конце строки убирает надпись, график остаётся.
- В Jupyter график показывается после выполнения ячейки, `plt.show()` не нужен. После показа фигура считается закрытой: `plt.savefig()` в следующей ячейке сохранит пустой лист, а `fig.savefig(...)` по имени фигуры — нужный график.
- Ошибка `TypeError: no numeric data to plot` означает попытку нарисовать линию или столбцы по текстовому столбцу без сводки.
- Ошибка ``ValueError: Could not interpret value `hour` for `x``` у seaborn означает, что с `data=` передано имя столбца, которого в таблице нет.
- Предупреждение `More than 20 figures have been opened` появляется, когда в ячейках создано много фигур; `plt.close('all')` закрывает их.

## 4. Фигура и оси

### plt.subplots(nrows=1, ncols=1, *, sharex=False, sharey=False, squeeze=True, width_ratios=None, height_ratios=None, subplot_kw=None, gridspec_kw=None, **fig_kw)

Семинар 8

Создать фигуру и оси на ней: одну область для графика или сетку панелей.

Параметры:

- `nrows`, `ncols` (целые, необязательные, по умолчанию 1): сколько рядов и столбцов панелей.
- `sharex`, `sharey` (логические или `'row'`, `'col'`, необязательные, по умолчанию `False`): общая ли шкала X или Y у панелей.
- `squeeze` (логическое, необязательный, по умолчанию `True`): при одной панели вернуть оси, а не массив из одного элемента.
- `width_ratios`, `height_ratios` (списки чисел, необязательные, по умолчанию `None`): относительные ширины столбцов и высоты рядов.
- `subplot_kw`, `gridspec_kw` (словари, необязательные, по умолчанию `None`): настройки осей и сетки; служебные.
- `**fig_kw`: параметры фигуры, из них в курсе нужен `figsize=(ширина, высота)` в дюймах; `dpi` — плотность точек на экране.

Возвращает:

- пару `(fig, axes)`: фигура и оси; при одной панели `axes` — один объект `Axes`, при нескольких — массив осей: `axes[0]`, `axes[1]`, для сетки `axes[0, 1]`.

```python
fig, ax = plt.subplots(figsize=(8, 4))
fig, axes = plt.subplots(1, 2, figsize=(12, 4))
```

| Пример | Результат | Пояснение |
|---|---|---|
| `type(ax).__name__` | `'Axes'` | одна панель — сразу оси |
| `fig.get_size_inches().tolist()` | `[12.0, 4.0]` | размер листа в дюймах у второй фигуры |
| `len(axes)` | `2` | две панели в ряд |
| `axes[0].figure is axes[1].figure` | `True` | обе на одной фигуре |

- Ловушка: `fig, ax = plt.subplots(1, 2)` даёт в `ax` массив, и `ax.set_title(...)` падает с `AttributeError: 'numpy.ndarray' object has no attribute 'set_title'`; для панелей нужны `axes[0]`, `axes[1]`.
- Применение: скелет любого графика курса: создать оси, нарисовать на них, подписать, сохранить фигуру.

### plt.close(fig=None)

## 5. Линия

### Series.plot(kind='line', ax=None, figsize=None, title=None, xlabel=None, ylabel=None, legend=True, rot=None, grid=None, stacked=False, **kwargs) и DataFrame.plot(...)

Семинар 8

Нарисовать сводку pandas: у Series по X индекс, по Y значения; у DataFrame по X индекс, по одной линии или набору столбцов на каждый столбец таблицы, с легендой из имён столбцов. У метода нет фиксированной подписи: все параметры именованные, ниже перечислены те, что есть в документации pandas 3.0.

Параметры:

- `kind` (строка, необязательный, по умолчанию `'line'`): вид графика: `'line'` линия, `'bar'` столбцы, `'barh'` горизонтальные столбцы, `'hist'` гистограмма, `'box'` ящик с усами, `'kde'` или `'density'` плотность, `'area'` область, `'pie'` круговая, `'scatter'` и `'hexbin'` только для DataFrame. Вместо `kind` можно вызвать метод с этим именем: `.plot.barh()`.
- `ax` (оси, необязательный, по умолчанию `None`): где рисовать; без него создаётся новая фигура.
- `subplots` (логическое или список групп столбцов, необязательный, по умолчанию `False`): у DataFrame — отдельная панель на каждый столбец.
- `sharex`, `sharey` (логические, необязательные): общие шкалы у панелей при `subplots=True`.
- `layout` (пара чисел, необязательный): сетка панелей при `subplots=True`.
- `figsize` (пара чисел, необязательный): размер новой фигуры в дюймах.
- `use_index` (логическое, необязательный, по умолчанию `True`): индекс как значения по X.
- `title` (строка или список, необязательный): заголовок; список — по заголовку на панель.
- `grid` (логическое, необязательный): сетка.
- `legend` (логическое или `'reverse'`, необязательный): легенда; у DataFrame по умолчанию есть.
- `style` (список или словарь, необязательный): стиль линий matplotlib по столбцам.
- `logx`, `logy`, `loglog` (логические, необязательные, по умолчанию `False`): логарифмические шкалы.
- `xticks`, `yticks` (списки, необязательные): положения делений.
- `xlim`, `ylim` (пары чисел, необязательные): границы осей.
- `xlabel`, `ylabel` (строки, необязательные): подписи осей; по умолчанию по X имя индекса, по Y пусто.
- `rot` (число, необязательный): поворот подписей делений в градусах; `rot=0` не поворачивать.
- `fontsize` (число, необязательный): размер шрифта делений.
- `colormap` (строка или палитра, необязательный): откуда брать цвета.
- `colorbar` (логическое, необязательный): шкала цвета, только для `'scatter'` и `'hexbin'`.
- `position` (число от 0 до 1, необязательный, по умолчанию 0.5): выравнивание столбцов.
- `table` (логическое или таблица, необязательный, по умолчанию `False`): таблица данных под графиком.
- `xerr`, `yerr` (числа, списки или столбцы, необязательные): усы погрешностей.
- `stacked` (логическое, необязательный, по умолчанию `False` у линий и столбцов): столбцы или области с накоплением.
- `secondary_y`, `mark_right` (служебные): вторая ось Y; в курсе не используется, две шкалы на одном графике не читаются.
- `include_bool` (логическое, необязательный, по умолчанию `False`): рисовать ли логические столбцы.
- `backend` (строка, необязательный): другая библиотека рисования; служебный.
- `**kwargs`: параметры метода matplotlib, из них в курсе `marker='o'` — точки на линии, `color` — цвет, `alpha` — прозрачность, `label` — имя линии для легенды.

Возвращает:

- оси `Axes`, на которых нарисовано; при `subplots=True` массив осей.

Линия по годам с маркерами и подписями:

```python
fig, ax = plt.subplots(figsize=(8, 4))
by_year.plot(ax=ax, marker='o')
ax.set_title('ДТП по годам')
ax.set_xlabel('Год')
ax.set_ylabel('Число ДТП')
```

| Пример | Результат | Пояснение |
|---|---|---|
| `len(ax.lines)` | `1` | одна линия |
| `ax.lines[0].get_xdata().tolist()[:3]` | `[2015, 2016, 2017]` | по X индекс сводки |
| `ax.lines[0].get_ydata().tolist()[:3]` | `[1392, 1313, 1266]` | по Y значения |
| `ax.get_title()` | `'ДТП по годам'` | заголовок поставлен |
| `by_year.plot(ax=plt.subplots()[1]).get_xlabel()` | `'datetime'` | без подписи ось X названа именем индекса |

Две линии на одних осях из таблицы 12 × 2:

```python
two = pd.crosstab(dtp['datetime'].dt.month, dtp['category'])[['Наезд на пешехода', 'Столкновение']]
fig, ax = plt.subplots(figsize=(8, 4))
two.plot(ax=ax, marker='o')
```

| Пример | Результат | Пояснение |
|---|---|---|
| `len(ax.lines)` | `2` | по линии на столбец таблицы |
| `[t.get_text() for t in ax.get_legend().get_texts()]` | `['Наезд на пешехода', 'Столкновение']` | легенда из имён столбцов |

- Ловушка: `value_counts()` ставит частые значения первыми, и линия по нему идёт зигзагом; перед линией нужен `sort_index()`. Линия по текстовому столбцу без сводки даёт `TypeError: no numeric data to plot`.
- Применение: линии по годам, месяцам, часам из `groupby(...).size()`; две линии — все ДТП и без лёгких — показывают, что падение числа ДТП связано с учётом.

### Axes.plot(*args, scalex=True, scaley=True, data=None, **kwargs)

Семинар 8

Нарисовать линию по двум последовательностям чисел напрямую, без pandas. В курсе нужен редко: сводки удобнее рисовать методом `.plot`.

Параметры:

- `*args`: значения по X и Y, либо только Y, тогда по X идут номера 0, 1, 2, …; третьим аргументом может идти строка формата вроде `'o-'`.
- `scalex`, `scaley` (логические, необязательные, по умолчанию `True`): подгонять ли шкалы под данные.
- `data` (таблица, необязательный, по умолчанию `None`): источник, из которого `x` и `y` берутся по именам столбцов.
- `**kwargs`: свойства линии: `marker`, `linestyle`, `linewidth`, `color`, `alpha`, `label`.

Возвращает:

- список нарисованных линий `Line2D`.

```python

lines = ax.plot(by_month.index, by_month.values, marker='o', label='Все ДТП')
ax.legend()
```

| Пример | Результат | Пояснение |
|---|---|---|
| `len(lines)` | `1` | одна линия |
| `lines[0].get_xdata().tolist()[:2]` | `[1, 2]` | месяцы по X |

- Ловушка: `ax.plot(by_month.values)` без X ставит по X номера точек 0…11 вместо месяцев.

## 6. Столбцы

### Series.plot.bar(...) и Series.plot.barh(...); DataFrame.plot(kind='bar', stacked=False, rot=None, ...)

Семинар 8

Столбцы по сводке: у Series столбец на каждое значение индекса; у DataFrame на каждую строку группа столбцов, по одному на столбец таблицы, рядом или с накоплением. Параметры те же, что у `.plot`; ключевые здесь `stacked`, `rot`, `ax`, `color`.

Горизонтальные столбцы для длинных названий, самое частое сверху:

```python
fig, ax = plt.subplots(figsize=(8, 4))
top6.plot.barh(ax=ax)
ax.invert_yaxis()
ax.set_xlabel('Число ДТП')
ax.set_ylabel('')
```

| Пример | Результат | Пояснение |
|---|---|---|
| `len(ax.patches)` | `6` | шесть столбцов |
| `int(ax.patches[0].get_width())` | `3994` | длина первого столбца — число ДТП |
| `ax.get_yticklabels()[0].get_text()` | `'Столкновение'` | первая подпись — первое значение сводки |
| `bool(ax.yaxis_inverted())` | `True` | ось развёрнута: первое значение сверху |

Столбцы с накоплением долей по годам:

```python
shares = pd.crosstab(dtp['datetime'].dt.year, dtp['severity'], normalize='index')[['Легкий', 'Тяжёлый', 'С погибшими']]
fig, ax = plt.subplots(figsize=(8, 4))
shares.plot(kind='bar', stacked=True, rot=0, ax=ax)
ax.set_ylabel('Доля ДТП')
```

| Пример | Результат | Пояснение |
|---|---|---|
| `len(ax.containers)` | `3` | три слоя — три набора столбцов |
| `len(ax.containers[0])` | `11` | по столбцу на каждый год |
| `round(float(sum(layer[0].get_height() for layer in ax.containers)), 3)` | `1.0` | слои одного столбца в сумме дают единицу |
| `round(float(ax.containers[1][0].get_y()), 3)` | `0.414` | второй слой начинается там, где кончился первый |

- Ловушка: pandas рисует первое значение внизу горизонтальной диаграммы; `ax.invert_yaxis()` или срез `[::-1]` перед рисованием ставит самое частое сверху. Без `stacked=True` столбцы встают рядом, без `rot=0` подписи годов повёрнуты на 90 градусов.
- Применение: виды ДТП, районы, погода — горизонтальными столбцами по `value_counts().head(n)`; доли тяжести по годам — накоплением по `crosstab(..., normalize='index')`.

## 8. Тепловая карта

### sns.heatmap(data, *, vmin=None, vmax=None, cmap=None, center=None, robust=False, annot=None, fmt='.2g', annot_kws=None, linewidths=0, linecolor='white', cbar=True, cbar_kws=None, cbar_ax=None, square=False, xticklabels='auto', yticklabels='auto', mask=None, ax=None, **kwargs)

Семинар 8

Раскрасить таблицу чисел: клетка на каждое значение, цвет по величине. Сводку готовит `crosstab` или `pivot_table`; имена осей карта берёт из имён индекса и столбцов таблицы.

Параметры:

- `data` (таблица или двумерный массив, обязательный): что раскрашивать.
- `vmin`, `vmax` (числа, необязательные, по умолчанию `None`): границы шкалы цвета; без них по данным.
- `cmap` (название палитры, необязательный, по умолчанию `None`): палитра; для чисел «больше — темнее» подходит `'Blues'`, `'Greys'`, `'Oranges'`.
- `center` (число, необязательный, по умолчанию `None`): значение, которому отвечает середина расходящейся палитры.
- `robust` (логическое, необязательный, по умолчанию `False`): границы шкалы по процентилям, чтобы выбросы не забивали цвет.
- `annot` (логическое или таблица, необязательный, по умолчанию `None`): писать ли число в клетке; таблица — свои подписи.
- `fmt` (строка формата, необязательный, по умолчанию `'.2g'`): формат чисел в клетках: `'d'` целые, `'.2f'` два знака.
- `annot_kws` (словарь, необязательный, по умолчанию `None`): оформление подписей.
- `linewidths`, `linecolor` (число и цвет, необязательные, по умолчанию 0 и `'white'`): линии между клетками.
- `cbar`, `cbar_kws`, `cbar_ax` (необязательные): шкала цвета справа, её настройки и оси.
- `square` (логическое, необязательный, по умолчанию `False`): квадратные клетки.
- `xticklabels`, `yticklabels` (`'auto'`, логическое, целое или список, необязательные): какие подписи делений показывать.
- `mask` (логическая таблица, необязательный, по умолчанию `None`): какие клетки скрыть.
- `ax` (оси, необязательный, по умолчанию `None`): где рисовать.
- `**kwargs`: параметры `Axes.pcolormesh`.

Возвращает:

- оси `Axes`.

```python

fig, ax = plt.subplots(figsize=(10, 4))
sns.heatmap(table, cmap='Blues', ax=ax)
```

| Пример | Результат | Пояснение |
|---|---|---|
| `np.asarray(ax.collections[0].get_array()).shape` | `(7, 24)` | семь дней на 24 часа |
| `int(np.asarray(ax.collections[0].get_array()).max())` | `129` | пятница, 18 часов |
| `ax.get_xlabel(), ax.get_ylabel()` | `('Час', 'День недели')` | подписи из имён Series |
| `tuple(int(v) for v in table.stack().idxmax())` | `(4, 18)` | клетка максимума: день, час |

- Ловушка: без `rename` у Series из одного столбца дат на обеих осях будет `datetime`. `annot=True` на 168 клетках не читается; числа уместны на маленьких таблицах. Радужные палитры для «больше — меньше» не годятся: у радуги нет порядка.
- Применение: день недели × час, месяц × день недели, освещение × вид ДТП; средние по клеткам — через `pivot_table` с `aggfunc='mean'` и `annot=True, fmt='.2f'`.

### sns.kdeplot(data=None, *, x=None, y=None, hue=None, weights=None, palette=None, hue_order=None, hue_norm=None, color=None, fill=None, multiple='layer', common_norm=True, common_grid=False, cumulative=False, bw_method='scott', bw_adjust=1, warn_singular=True, log_scale=None, levels=10, thresh=0.05, gridsize=200, cut=3, clip=None, legend=True, cbar=False, cbar_ax=None, cbar_kws=None, ax=None, **kwargs)

Семинар 9

Сглаженная кривая плотности вместо гистограммы: для непрерывных величин и для сравнения групп разного размера.

Параметры:

- `data` (таблица, необязательный, по умолчанию `None`): откуда брать столбцы по именам.
- `x`, `y` (имя столбца или Series, необязательные): что сглаживать; `x` — кривая, оба — двумерная плотность линиями уровня.
- `hue` (имя столбца, необязательный, по умолчанию `None`): кривая на каждую группу.
- `weights` (имя столбца, необязательный, по умолчанию `None`): веса значений.
- `palette`, `hue_order`, `hue_norm` (необязательные, по умолчанию `None`): цвета и порядок групп `hue`.
- `color` (цвет, необязательный, по умолчанию `None`): цвет кривой без `hue`.
- `fill` (логическое, необязательный, по умолчанию `None`): закрасить площадь под кривой; тогда на осях не линии, а заливки.
- `multiple` (`'layer'`, `'stack'`, `'fill'`, необязательный, по умолчанию `'layer'`): как расположить группы; `'stack'` и `'fill'` требуют заливки.
- `common_norm` (логическое, необязательный, по умолчанию `True`): одна единица площади на все группы вместе; `False` — единица на каждую группу, сравниваются формы, а не размеры.
- `common_grid` (логическое, необязательный, по умолчанию `False`): общая сетка точек для всех групп.
- `cumulative` (логическое, необязательный, по умолчанию `False`): накопленная кривая вместо плотности.
- `bw_method` (`'scott'`, `'silverman'` или число, необязательный, по умолчанию `'scott'`): способ выбора ширины сглаживания.
- `bw_adjust` (число, необязательный, по умолчанию 1): множитель ширины сглаживания; больше единицы — глаже.
- `warn_singular` (логическое, необязательный, по умолчанию `True`): предупреждать о группе из одинаковых значений, для которой плотность не строится.
- `log_scale` (логическое или число, необязательный, по умолчанию `None`): логарифмическая шкала.
- `levels`, `thresh` (число или список; число, необязательные): линии уровня двумерной плотности; служебные.
- `gridsize` (целое, необязательный, по умолчанию 200): из скольких точек состоит кривая.
- `cut` (число, необязательный, по умолчанию 3): на сколько ширин сглаживания кривая выходит за крайние значения; `0` обрезает по данным.
- `clip` (пара чисел, необязательный, по умолчанию `None`): границы, за которые кривая не выходит.
- `legend` (логическое, необязательный, по умолчанию `True`): легенда для `hue`.
- `cbar`, `cbar_ax`, `cbar_kws` (для двумерной плотности): шкала цвета; служебные.
- `ax` (оси, необязательный, по умолчанию `None`): где рисовать.
- `**kwargs`: параметры линии, например `linewidth`.

Возвращает:

- оси `Axes`; подпись оси Y ставится `'Density'`, заменяется `set_ylabel`.

```python
fig, ax = plt.subplots(figsize=(8, 4))
sns.kdeplot(data=drivers, x='experience_clean', hue='gender', common_norm=False, ax=ax)
```

| Пример | Результат | Пояснение |
|---|---|---|
| `len(ax.lines)` | `2` | кривая на каждый пол |
| `round(float(np.trapezoid(ax.lines[0].get_ydata(), ax.lines[0].get_xdata())), 2)` | `1.0` | площадь под кривой — единица: common_norm=False |
| `ax.get_ylabel()` | `'Density'` | подпись оси Y по-английски, заменить |
| `sns.kdeplot(data=drivers, x='experience_clean', hue='gender', ax=plt.subplots()[1]).lines.__len__()` | `2` | при common_norm по умолчанию кривых тоже две, но площади делятся по размеру групп |

- Ловушка: при `common_norm` по умолчанию кривая малой группы в разы ниже и выглядит плоской. Для целых значений, таких как час суток, кривая выходит за пределы 0–23 и сглаживает пик: там нужна гистограмма с `discrete=True`. Порядок линий в `ax.lines` не совпадает с порядком легенды.
- Применение: стаж, возраст, суммы по группам разного размера.

### DataFrame.corr(method='pearson', min_periods=1, numeric_only=False)

Семинар 9

Матрица коэффициентов корреляции между столбцами таблицы: от −1 при строгой обратной связи до 1 при строгой прямой, около нуля без линейной связи; на диагонали единицы.

Параметры:

- `method` (`'pearson'`, `'kendall'`, `'spearman'` или функция, необязательный, по умолчанию `'pearson'`): какой коэффициент; в курсе Пирсона.
- `min_periods` (целое, необязательный, по умолчанию 1): сколько пар значений без пропусков нужно для коэффициента.
- `numeric_only` (логическое, необязательный, по умолчанию `False`): брать только числовые столбцы; с `False` текстовый столбец даёт `ValueError`.

Возвращает:

- таблицу `DataFrame` с теми же именами по строкам и столбцам.

```python
numeric = ['participants_count', 'vehicles_count', 'dead_count', 'injured_count', 'road_defects', 'hour']
corr = dtp[numeric].corr()                                                # матрица корреляций
fig, ax = plt.subplots(figsize=(7, 5))
sns.heatmap(corr, cmap='coolwarm', center=0, annot=True, fmt='.2f', ax=ax)   # расходящаяся палитра с нулём в середине
```

| Пример | Результат | Пояснение |
|---|---|---|
| `corr.shape` | `(6, 6)` | столбец на столбец |
| `round(float(corr.loc['participants_count', 'injured_count']), 2)` | `0.68` | чем больше участников, тем больше раненых |
| `round(float(corr.loc['dead_count', 'injured_count']), 2)` | `-0.17` | пострадавший либо погиб, либо ранен |
| `round(float(drivers[['vehicle_age', 'experience_clean']].corr().iloc[0, 1]), 2)` | `-0.03` | связи нет |
| `len(ax.texts)` | `36` | annot=True подписал каждую клетку |
| `ax.texts[1].get_text()` | `'0.50'` | fmt='.2f' — два знака |
| `dtp.corr(numeric_only=True).shape` | `(8, 8)` | без списка в матрицу попали координаты |

- Ловушка: `dtp.corr()` по таблице с текстом даёт `ValueError: could not convert string to float`; `numeric_only=True` спасает от ошибки, но тянет в матрицу координаты и номера, у которых корреляция смысла не имеет. Для матрицы корреляций палитра расходящаяся, `coolwarm` с `center=0`: у последовательной `Blues` нет середины, и знак теряется. Корреляция около нуля означает «нет прямой линии», а не «нет связи»: сводка по группам может показать разницу, которую корреляция не видит.
- Применение: раздел «Корреляционный анализ» этапа 2 проекта; список столбцов выбирается по смыслу.

- `x`, `y` (имена столбцов или Series, необязательные): по X периоды, по Y что сворачивать.
- `hue` (имя столбца, необязательный, по умолчанию `None`): линия на каждую группу.
- `size`, `style` (имена столбцов, необязательные, по умолчанию `None`): толщина и штрих линии по группам.
- `units` (имя столбца, необязательный, по умолчанию `None`): отдельная линия на каждую единицу без сводки; служебный.
- `weights` (имя столбца, необязательный, по умолчанию `None`): веса для сводки.
- `palette`, `hue_order`, `hue_norm` (необязательные, по умолчанию `None`): цвета и порядок групп `hue`; для упорядоченных групп, например лет, последовательная палитра `'viridis'`.
- `sizes`, `size_order`, `size_norm` (необязательные, по умолчанию `None`): диапазон и порядок толщин для `size`.
- `dashes`, `markers`, `style_order` (необязательные): штрихи и маркеры для групп `style`.
- `estimator` (строка или функция, необязательный, по умолчанию `'mean'`): какая сводка: `'mean'`, `'median'`, `'sum'`; `None` — рисовать все точки без сводки.
- `errorbar` (строка, пара или `None`, необязательный, по умолчанию `('ci', 95)`): какой интервал: доверительный `'ci'`, стандартное отклонение `'sd'`, ошибка среднего `'se'`, размах процентилей `'pi'`; `None` убирает полосу.
- `n_boot` (целое, необязательный, по умолчанию 1000): сколько повторных выборок для интервала.
- `seed` (целое, необязательный, по умолчанию `None`): зерно случайности интервала.
- `orient` (`'x'` или `'y'`, необязательный, по умолчанию `'x'`): по какой оси идёт сводка.
- `sort` (логическое, необязательный, по умолчанию `True`): сортировать точки по `x` перед соединением.
- `err_style` (`'band'` или `'bars'`, необязательный, по умолчанию `'band'`): полоса или усы.
- `err_kws` (словарь, необязательный, по умолчанию `None`): оформление полосы.
- `legend` (`'auto'`, `'brief'`, `'full'` или `False`, необязательный, по умолчанию `'auto'`): какая легенда; `'full'` показывает все группы.
- `ci` (устаревший, по умолчанию `'deprecated'`): прежнее имя `errorbar`; не использовать.
- `ax` (оси, необязательный, по умолчанию `None`): где рисовать.
- `**kwargs`: параметры `Axes.plot`, например `marker='o'`.

Возвращает:

- оси `Axes`: линия в `ax.lines[0]`, полоса в `ax.collections[0]`.

```python
dtp['fatal'] = dtp['dead_count'] > 0                                      # ДТП с погибшими
fig, ax = plt.subplots(figsize=(8, 4))
sns.lineplot(data=dtp, x='hour', y='fatal', ax=ax)                        # доля по часам с полосой
```

| Пример | Результат | Пояснение |
|---|---|---|
| `len(ax.lines)` | `1` | одна линия — доля по часам |
| `round(float(ax.lines[0].get_ydata().max()), 3)` | `0.259` | наибольшая доля ДТП с погибшими, 1 час ночи |
| `len(ax.collections)` | `1` | полоса доверительного интервала |

- Ловушка: `y='dead_count'` без маски даёт среднее число погибших, а не долю; `errorbar=None` прячет предупреждение о малых группах вместе с полосой. Границы полосы считаются случайными выборками и от запуска к запуску чуть меняются.

## 15. Панели одной командой

Функции `displot`, `catplot` и `pairplot` строят сетку графиков и возвращают не оси, а объект-сетку: `FacetGrid` у первых двух, `PairGrid` у третьей. Оси они не принимают, фигура лежит в `g.figure`, общий заголовок ставится `g.figure.suptitle(...)`, панели лежат в `g.axes`.

### sns.displot(data=None, *, x=None, y=None, hue=None, row=None, col=None, weights=None, kind='hist', rug=False, rug_kws=None, log_scale=None, legend=True, palette=None, hue_order=None, hue_norm=None, color=None, col_wrap=None, row_order=None, col_order=None, height=5, aspect=1, facet_kws=None, **kwargs)

Семинар 9

Распределения по панелям: гистограмма или плотность на каждую группу.

Параметры:

- `data` (таблица, необязательный, по умолчанию `None`): откуда брать столбцы по именам.
- `x`, `y` (имена столбцов, необязательные): что раскладывать.
- `hue` (имя столбца, необязательный, по умолчанию `None`): группы цветом внутри панели.
- `row`, `col` (имена столбцов, необязательные, по умолчанию `None`): группы по строкам и столбцам сетки — панель на каждое значение.
- `weights` (имя столбца, необязательный, по умолчанию `None`): веса значений.
- `kind` (`'hist'`, `'kde'`, `'ecdf'`, необязательный, по умолчанию `'hist'`): какой график в панели.
- `rug`, `rug_kws` (логическое; словарь, необязательные): штрихи значений под графиком; служебные.
- `log_scale` (логическое или число, необязательный, по умолчанию `None`): логарифмическая шкала.
- `legend` (логическое, необязательный, по умолчанию `True`): легенда для `hue`.
- `palette`, `hue_order`, `hue_norm`, `color` (необязательные, по умолчанию `None`): цвета и порядок групп.
- `col_wrap` (целое, необязательный, по умолчанию `None`): сколько панелей в ряду, дальше новый ряд; только с `col` без `row`.
- `row_order`, `col_order` (списки, необязательные, по умолчанию `None`): порядок панелей.
- `height` (число, необязательный, по умолчанию 5): высота панели в дюймах.

- `facet_kws` (словарь, необязательный, по умолчанию `None`): параметры сетки, например `{'sharey': False}` — своя шкала Y у каждой панели.
- `**kwargs`: параметры функции панели, например `discrete=True` для `histplot`.

Возвращает:

- сетку `FacetGrid`.

```python

```

| Пример | Результат | Пояснение |
|---|---|---|
| `type(g).__name__` | `'FacetGrid'` | возвращается сетка, не оси |
| `len(g.figure.axes)` | `7` | панель на каждый день недели |

| `g.axes.flat[4].get_subplotspec().rowspan.start` | `1` | пятая панель во втором ряду: col_wrap=4 |
| `tuple(int(v) for v in g.figure.get_size_inches())` | `(10, 5)` | четыре панели по 2,5 дюйма в ряд, два ряда |

## 16. Plotly: интерактивные графики и карта

- `config` (словарь, необязательный, по умолчанию `None`): панель инструментов фигуры.
- `auto_play` (логическое, необязательный, по умолчанию `True`): запускать анимацию при открытии.
- `include_plotlyjs` (`True`, `False`, `'cdn'`, `'directory'` или путь, необязательный, по умолчанию `True`): как подключить библиотеку: `True` встраивает её в файл, около пяти мегабайт; `'cdn'` подключает из интернета, файл весит килобайты.
- `include_mathjax` (`False`, `'cdn'` или путь, необязательный, по умолчанию `False`): библиотека формул.
- `post_script` (строка, необязательный, по умолчанию `None`): свой код JavaScript после фигуры; служебный.
- `full_html` (логическое, необязательный, по умолчанию `True`): целая страница или только фрагмент для вставки.
- `animation_opts` (словарь, необязательный, по умолчанию `None`): настройки анимации.
- `validate` (логическое, необязательный, по умолчанию `True`): проверять фигуру перед записью.
- `default_width`, `default_height` (строки, необязательные, по умолчанию `'100%'`): размер фигуры на странице.
- `auto_open` (логическое, необязательный, по умолчанию `False`): открыть файл в браузере сразу.
- `div_id` (строка, необязательный, по умолчанию `None`): идентификатор блока на странице; служебный.

Возвращает:

- `None`; файл появляется по пути `file`.

```python
os.makedirs('img', exist_ok=True)
fig = px.line(monthly, x='month', y='count', color='year', markers=True, title='ДТП по месяцам и годам')
fig.write_html('img/reference-by-month.html', include_plotlyjs='cdn')
```

| Пример | Результат | Пояснение |
|---|---|---|
| `os.path.getsize('img/reference-by-month.html') < 100_000` | `True` | с cdn файл весит килобайты |
| `'cdn.plot.ly' in open('img/reference-by-month.html', encoding='utf-8').read()` | `True` | библиотека подключается из интернета |

- Ловушка: `fig.write_image('...png')` требует пакет kaleido, которого в окружении нет; интерактивные фигуры сохраняются в HTML, картинки для отчёта рисует matplotlib. Файл со встроенной библиотекой весит около пяти мегабайт независимо от числа точек.
- Применение: карта или интерактивная линия для читателя без Python.

## 17. Типичные ошибки и их сообщения

| Сообщение или симптом | Причина | Что делать |
|---|---|---|
| `TypeError: no numeric data to plot` | линия или столбцы по текстовому столбцу без сводки | сначала `value_counts` или `groupby`, потом `.plot` |
| ``ValueError: Could not interpret value `hour` for `x`. An entry with this name does not appear in `data`.`` | с `data=` передано имя столбца, которого в таблице нет | создать столбец или передать Series через `x=` |
| `AttributeError: 'numpy.ndarray' object has no attribute 'set_title'` | `plt.subplots(1, 2)` вернул массив осей | обращаться к панелям `axes[0]`, `axes[1]` |
| `AttributeError: 'Axes' object has no attribute 'savefig'` | сохранение вызвано у осей | `ax.figure.savefig(...)` или `fig.savefig(...)` |
| файл картинки в две тысячи байт, белый лист | `plt.savefig()` в другой ячейке после показа графика | `fig.savefig(...)` по имени фигуры |
| линия идёт зигзагом | сводка через `value_counts()` без `sort_index()` | `value_counts().sort_index()` или `groupby(...).size()` |
| по оси X номера 0, 1, 2 вместо годов | `ax.plot(values)` без X | `series.plot(ax=ax)` или `ax.plot(index, values)` |
| два рисунка вместо двух линий на одном | второй `.plot()` без `ax=ax` или в другой ячейке | все линии на одних осях в одной ячейке |
| самое частое значение внизу горизонтальных столбцов | pandas рисует первый элемент внизу | `ax.invert_yaxis()` или срез `[::-1]` |
| столбцы гистограммы съехали с целых значений или слиплись | нет `discrete=True` | `sns.histplot(x=..., discrete=True)` |
| лишний ящик из двух-трёх значений | `order` не передан | `order=[...]` с нужными группами |
| на обеих осях тепловой карты `datetime` | Series без имён | `.rename('Месяц')`, `.rename('Час')` |
| подпись оси `Count` или `count` по-английски | seaborn подписал ось сам | `ax.set_ylabel('Число ДТП')` |
| `UserWarning: No artists with labels found to put in legend` | `ax.legend()` при линиях без `label` | задать `label=` при рисовании |
| `RuntimeWarning: More than 20 figures have been opened` | много фигур в цикле или тестах | `plt.close('all')` |
| `ValueError: could not convert string to float: '...'` | `corr()` по таблице с текстовыми столбцами | список числовых столбцов: `df[columns].corr()` |
| ноль на корреляционной карте синий или тёмный | последовательная палитра или нет `center=0` | `cmap='coolwarm', center=0` |
| слои гистограммы с `hue` наложены, высоты не сходятся | `multiple='layer'` по умолчанию | `multiple='stack'` |
| легенда `True`/`False` | в `hue` передана маска вместо столбца с названиями групп | столбец с названиями через `np.where` или `map` |
| кривая плотности малой группы плоская | `common_norm=True` делит площадь между группами по размеру | `common_norm=False` |
| кривая плотности за пределами возможных значений | `kdeplot` на целой величине вроде часа | гистограмма с `discrete=True` |
| линия доли без полосы | `errorbar=None` или линия по сводке `groupby` | `sns.lineplot(data=..., x=..., y=...)` по сырой таблице |
| `AttributeError: Rectangle.set() got an unexpected keyword argument 'col'` | `histplot` не умеет панели | `sns.displot(..., col=..., col_wrap=...)` |
| семь панелей в один ряд или столбиком | нет `col_wrap` или взят `row=` | `col=..., col_wrap=4` |
| `AttributeError: 'FacetGrid' object has no attribute '_suptitle'` | сетка передана туда, где ждут фигуру | `g.figure` |
| `ValueError: Value of 'x' is not the name of a column in 'data_frame'` | сводка передана в plotly без столбцов | `.reset_index(name='count')` |
| одна ломаная через все годы подряд в plotly | не задан `color` | `color='year'` |
| карта в Иране или в океане | `lat` и `lon` перепутаны местами | `lat='lat', lon='lon'` |
| карта без подложки | нет интернета | дождаться сети или показать рассеяние `ax.scatter` |
| файл HTML около пяти мегабайт | `write_html` со встроенной библиотекой | `include_plotlyjs='cdn'` |
| `ValueError: Image export using the "kaleido" engine requires the Kaleido package` | `fig.write_image` без kaleido | `fig.write_html(...)` |
| `DeprecationWarning: *scatter_mapbox* is deprecated` | устаревшее имя функции карты | `px.scatter_map` |
